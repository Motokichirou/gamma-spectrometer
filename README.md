Портативный цилиндрический гамма-спектрометр на кристалле NaI(Tl) Ø63×63 мм и ФЭУ Hamamatsu R1307, с интерфейсом USB-C, совместимым с [BecqMoni](https://github.com/Am6er/BecqMoni) / AtomSpectra (протокол shproto).

> 📚 **Документация:** [обзор аппаратной части](docs/ru/hardware.md) · [прошивка](docs/ru/firmware.md) · [протокол shproto](docs/ru/protocol.md) · [ПО на PC](host/README.md)

> ✅ **Ноябрь 2026: прибор собран и работает с BecqMoni.** На временном детекторе NaI(Tl) 40×40 —
> **Cs-137 6.9 % FWHM**, ФЭУ на ~750 В. Следующий этап — штатный NaI(Tl) Ø63×63 + R1307.

---

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Детектор | NaI(Tl) Ø63×63 мм |
| ФЭУ | Hamamatsu R1307 (8 каскадов, Ø76 мм) |
| Диапазон энергий | 50 кэВ – 3.5 МэВ |
| FWHM @ Cs-137 | **6.9 % измерено** (NaI 40×40, ФЭУ от сборки Sypher); цель для 63×63 — 6.0–6.5 % |
| Каналов спектра | 8192 |
| Скорость счёта | до ~30 000 имп/с |
| МК | STM32G474CBT6 (LQFP-48) @ 156 МГц, 12-бит АЦП (сигнал 3.47 Мвыб/с), встроенные ОУ |
| ВВ питание | 0 … −1200 В, рабочее ~750 В (MAX1847 + 4-ступенчатый умножитель CW) |
| Интерфейс | USB-C → UART 600 кбит/с (FT231X), протокол shproto |
| Питание | USB 5 В, ~370 мА |
| Форм-фактор | Цилиндрический стек, платы Ø45 мм |

## Аппаратная архитектура

### Стек плат (снизу → вверх)

```
 ┌─────────────────────────────────────────┐
 │  USB/Power board  Ø45 mm               │  ← кабель USB-C
 │  LP5907 · AMS1117 · TPS60400 · FT231X  │
 ├─────────────────────────────────────────┤
 │  HV board         Ø45 mm               │
 │  MAX1847 · IRLML0060 · CW ×4 · ≤−1200 V│
 ├─────────────────────────────────────────┤
 │  MCU board        Ø45 mm               │
 │  STM32G474CBT6 · шейпер · ADC · SPI    │
 ├─────────────────────────────────────────┤
 │  Divider board    Ø42–45 mm            │  ← ФЭУ Hamamatsu R1307 + NaI(Tl)
 │  R1307 divider · MMBTA42 buffers       │
 │  ADA4817-1 TIA (Zt = 2.7 kΩ)           │
 └─────────────────────────────────────────┘
```

Межплатные соединения — без разъёмов:
- **Шина стека**: цанговые пины Ø1.5 мм на дуге R20 мм, соосные на всех платах (44 посадочных
  места: USB 11, ВВ 15, МК 13, делитель 5); по ней же идёт питание делителя ±5 В_A
- **Сигнал** (делитель → МК): тонкий коаксиал, припаянный к пятакам
- **−HV**: экранированный провод ≥5 кВ (ВВ → делитель) через отверстие Ø4.5 мм в плате МК
- **Pt1000** на корпусе кристалла: витая пара на пятаки платы МК
- Механика: по три стойки M2.5 в центре каждой платы

### Цепь сигнала

```
NaI(Tl) + R1307            Плата делителя                 Плата МК
─────────────    ─────────────────────────────   ──────────────────────────────────
 Сцинтилляция →   Делитель (цепочка 7.72 МОм)   →  OPAMP1: интегратор, τ=1 мкс
 τ_спада=230 нс   Активные буферы (Dy6/7/8)        OPAMP2: интегратор, τ=1.8 мкс
 ФЭУ на ~750 В    ADA4817 TIA, Zt=2.7 кОм       →  PGA ×4 (OPAMP3)
                                                   V_ADC = baseline 0.394 В
                                                   ADC3_IN1, 3.47 Мвыб/с
                                                   импульс: фронт 5–6 отсчётов, FWHM 3.6 мкс
                                                   амплитуда по эталону формы (64 фазы)
                                                   гистограмма 8192 кан. → USB
```

**Полярность АЦП:** анод забирает ток ⇒ выход TIA вверх ⇒ импульсы **положительны** относительно baseline 0.394 В → `amplitude = sample − baseline`

### Калибровка энергии (измерено: NaI 40×40, ~755 В, Ra-226)

Калибровка по 5 точкам в BecqMoni: `E[кэВ] = −6.01 + 0.5518·x + 6.63·10⁻⁶·x²` (x — канал).
Изгиб шкалы — в основном непропорциональность световыхода NaI, а не электроника.

| Линия | Энергия | Канал / 8192 | Найдено по калибровке |
|---|---|---|---|
| Pb-214 | 295 кэВ | 549 | 299 кэВ |
| Pb-214 | 352 кэВ | 652 | 356 кэВ |
| Bi-214 | 609 кэВ | 1102 | 610 кэВ |
| Cs-137 | 662 кэВ | ≈1194 | — |
| Bi-214 | 1120 кэВ | 1990 | 1118 кэВ |
| Bi-214 | 1764 кэВ | 3107 | 1773 кэВ |
| Потолок | 3.5 МэВ | ≈5930 | — |

Положение пиков задаётся ВВ: для другого детектора Cs выставляется на канал ~1160–1200 подстройкой ВВ.

## Разрешение (измерено, Cs-137)

| Конфигурация | FWHM |
|---|---|
| Первый тракт (импульс короче отсчёта АЦП), ~1040 В | 7.6–7.8 % |
| Шейпер V2 (фронт 5–6 отсчётов), 1030 В | 6.99 % |
| Шейпер V2 + R417 2.7 кОм, ~755 В | 7.1 % |
| То же, кристалл 40×40 с большим световыходом, 735 В | **6.9 %** |
| Тот же детектор Sypher на своей электронике (по энергии, кэВ) | 7.08 % |

Скан ВВ на новом тракте раскладывается как FWHM² = a² + (b/канал)²: постоянная часть a ≈ 7.0 %
(кристалл + ФЭУ + обработка) и шум электроники ≈0.8 % на канале Cs. Разрешение ограничено детектором,
а не трактом. Разрешение сравнивается только по энергии: у трактов с нелинейной шкалой процент
по каналу выглядит лучше реального. Подробности — [`firmware/board_g474cb/SPEC.md`](firmware/board_g474cb/SPEC.md) §10.

## Протокол: shproto / AtomSpectra

Совместим с [BecqMoni](https://github.com/Am6er/BecqMoni) и [nanopro](https://github.com/Am6er/nanopro).

- UART 600 000 бит/с, 8N1
- Кадр: `0xFE | CMD | PAYLOAD (с байт-стаффингом) | CRC16-MODBUS | 0xA5`
- Cmd `0x01`: спектр (до 8192 × 32-битных каналов)
- Cmd `0x04`: статус (прошедшее время, CPS, число невалидных импульсов)
- Keep-alive: `0xFF` от ПК каждую ~1 с
