Портативный цилиндрический гамма-спектрометр на кристалле NaI(Tl) Ø63×63 мм и ФЭУ Hamamatsu R1307, с интерфейсом USB-C, совместимым с [BecqMoni](https://github.com/Am6er/BecqMoni) / AtomSpectra (протокол shproto).

> 📚 **Документация:** [обзор аппаратной части](docs/ru/hardware.md) · [прошивка](docs/ru/firmware.md) · [протокол shproto](docs/ru/protocol.md) · [ПО на PC](host/README.md) · [симуляции](docs/ru/simulations.md)

> 🏭 **Октябрь 2026:** платы в производстве, все комплектующие на руках. Следующий шаг — сборка
> и первое включение.

## Ключевые характеристики

| Параметр | Значение |
|---|---|
| Детектор | NaI(Tl) Ø63×63 мм |
| ФЭУ | Hamamatsu R1307 (8 каскадов, Ø76 мм) |
| Диапазон энергий | 50 кэВ – 3.5 МэВ |
| Целевое FWHM @ Cs-137 | 6.0–6.5 % |
| Каналов спектра | 8192 |
| Скорость счёта | до ~30 000 имп/с |
| МК | STM32G474CBT6 (LQFP-48) @ 170 МГц, 12-бит АЦП 4 Мвыб/с, встроенные ОУ |
| ВВ питание | 0 … −1500 В (MAX1847 + 4-ступенчатый умножитель CW) |
| Интерфейс | USB-C → UART 600 кбит/с (FT231X), протокол shproto |
| Питание | USB 5 В, ~370 мА |
| Форм-фактор | Цилиндрический стек, платы Ø45 мм |

## Аппаратная архитектура

### Стек плат (снизу → вверх)

```
 ┌─────────────────────────────────────────┐
 │  USB/Power board  Ø45 mm               │  ← кабель USB-C
 │  LP5907 · AMS1117 · TPS60400 · FT231X  │
 ├─────────────────────────────────────────┤
 │  HV board         Ø45 mm               │
 │  MAX1847 · IRLML0060 · CW ×4 · −1500 V │
 ├─────────────────────────────────────────┤
 │  MCU board        Ø45 mm               │
 │  STM32G474CBT6 · CR-RC² · ADC · SPI    │
 ├─────────────────────────────────────────┤
 │  Divider board    Ø42–45 mm            │  ← ФЭУ Hamamatsu R1307 + NaI(Tl)
 │  R1307 divider · MMBTA42 buffers       │
 │  ADA4817-1 TIA (Zt = 499 Ω)            │
 └─────────────────────────────────────────┘
```

Межплатные соединения — без разъёмов:
- **Шина стека**: цанговые пины Ø1.5 мм на дуге R20 мм, соосные на всех платах (44 посадочных
  места: USB 11, ВВ 15, МК 13, делитель 5); по ней же идёт питание делителя ±5 В_A
- **Сигнал** (делитель → МК, ~470 мВ для Cs-137): тонкий коаксиал, припаянный к пятакам
- **−HV**: экранированный провод ≥5 кВ (ВВ → делитель) через отверстие Ø4.5 мм в плате МК
- **Pt1000** на корпусе кристалла: витая пара на пятаки платы МК
- Механика: по три стойки M2.5 в центре каждой платы

### Цепь сигнала

```
NaI(Tl) + R1307            Плата делителя                 Плата МК
─────────────    ─────────────────────────────   ──────────────────────────────────
 Сцинтилляция →   Делитель (цепочка 7.72 МОм)   →  CR  (OPAMP1, τ=1 мкс)
 τ_спада=230 нс   Активные буферы (Dy6/7/8)        RC  (OPAMP2, τ=510 нс)
 I_анода(Cs-137)  ADA4817 TIA, Zt=499 Ω, BW≈92 МГц →  PGA ×4 (OPAMP3)
  = 0.94 мА       V_вых = +469 мВ (Cs-137)         V_ADC = baseline 0.408 В
                                                   ADC1_IN12, 4 Мвыб/с
                                                   гистограмма 8192 кан. → USB
```

**Полярность АЦП:** анод забирает ток ⇒ выход TIA вверх ⇒ импульсы **положительны** относительно baseline 0.408 В → `amplitude = sample − baseline`

## Бюджет шумов (sim3)

| Вклад | FWHM |
|---|---|
| Статистика ФЭУ R1307 + NaI(Tl) | 6.3 % |
| Пульсации ВВ (после выходного RC-фильтра — единицы нВ) | пренебрежимо |
| Нелинейность АЦП (12-бит, ENOB ~10.5) | 0.1 % |
| Шум электроники (σ = 76.9 мкВ rms с TIA на ADA4817) | **0.05 %** |
| Цифровая обработка (эталон формы, 30 кимп/с, Монте-Карло) | 0.44 % |
| **Итого** | **≈6.3 %** |

Электроника и обработка дают на порядок меньше статистики ФЭУ — разрешение ограничено
кристаллом и ФЭУ, а не трактом.

## Протокол: shproto / AtomSpectra

Совместим с [BecqMoni](https://github.com/Am6er/BecqMoni) и [nanopro](https://github.com/Am6er/nanopro).

- UART 600 000 бит/с, 8N1
- Кадр: `0xFE | CMD | PAYLOAD (с байт-стаффингом) | CRC16-MODBUS | 0xA5`
- Cmd `0x01`: спектр (до 8192 × 32-битных каналов)
- Cmd `0x04`: статус (прошедшее время, CPS, число невалидных импульсов)
- Keep-alive: `0xFF` от ПК каждую ~1 с
