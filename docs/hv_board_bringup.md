# Плата ВВ — запуск первого экземпляра

Журнал включения и чек-лист прозвонки. Связи взяты из `gamma_spectrometer.kicad_pcb` (2026-11-01).
Схема и расчёты — `docs/hv_board_schematic.md`.

---

## 1. Журнал 2026-11-01

Сборка: низ (B.Cu) и верх (F.Cu) спаяны, **плата не мыта**. Питание — ЛБП 5 В на пины стека
`+5V_HV`/`GND`; `HV_ENABLE` — отдельным источником (SHDN ≈ 2.78 В); `HV_CONTROL` — DC с генератора
осциллографа; щуп 1:100 на −HV_out.

- **R202 (FREQ, 180 к) — один конец не припаялся.** Пад 1 (GND) без дорожки, земля идёт через виа
  в паде на пад 3 U202 снизу ⇒ припой уходит в виа. Допаяно с флюсом и запасом припоя.
- Первое включение: ток ≈ 0 (ЛБП с шагом 10 мА), +5V_HV на C207 = 5.0 В, `HV_MONITOR` = 2.435 В,
  SHDN = 2.78 В (порог по даташиту **2.0 В** — это единица), **VL = 0.89 В** (норма ≈ 4.2 В):
  MAX1847 не работал.
- Затем «завелось» (что именно изменилось — не записано, ⇒ подозрение на ненадёжную пайку U201):
  `HV_CONTROL` = **2.7 мВ** → щуп **−460 В**, `HV_MONITOR` = 1.67 В (≈ −470…−510 В, сходится).
  Ожидалось −454.5 × 0.0027 ≈ **−1.2 В**.
- Далее получено **−1750 В** (уставка на этот момент не записана), пробоя по воздуху не было.
  Нагрузка элементов при −1750 В: C210–C217 ≈ 440 В на 500-вольтовых — на грани; резисторы 1206
  ≈ 175 В — в норме; сток Q201 под снаббером; HV_MONITOR ≈ −0.3 В (МК не был подключён).

**Вывод: преобразователь и умножитель работают, петля обратной связи НЕ регулирует.**
Подозреваемые по убыванию вероятности:
1. непропай вывода 6 (FB) U201 или вообще ножек U201 (VL сначала 0.89 В, потом заработало);
2. обрыв цепочки FB: пайка R207, R209–R217 или переход R217 (F.Cu) → CW_out (C13a201, B.Cu);
3. утечка на FB: флюс между выводами 5 (REF, +1.25 В) и 6 (FB) — при CONTROL ≈ 0 даёт
   |V| ≈ 1.25 В × 1 ГОм / R_утечки (−460 В ⇔ ≈ 2.7 МОм);
4. R208 не припаян (одно это даёт ≈ 0 В, а не разгон — но проверить).

### 2.7 После прозвонки

Помыть плату (Solins-US в УЗ → дистиллят 2–3 раза → ИПС → сушка 1 ч 60–70 °C) и повторить
включение с CONTROL = 0: ожидаем −HV ≈ 0, затем по шагам 0.11 / 0.22 / 0.44 В (−50 / −100 / −200 В).
**Записывать уставку на каждом шаге.**
