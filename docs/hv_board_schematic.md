# Плата ВВ питания — схемотехника

## Назначение
Средняя плата стека. Генерирует регулируемое высокое напряжение 0 … −1500 В
для ФЭУ R1307. Управляется сигналом HV_CONTROL от платы МК.
Питается напрямую от +5В USB через шину +5V_HV нижнего header'а.

## Стек и межплатные соединения

```
┌─ Плата МК (сверху) ──────────────────────────────────────────┐
│  Верхний 2×N header (размер при разводке)                      │
│  HV_CONTROL → (с платы МК вниз к нам)                         │
│  HV_MONITOR ← (от нас вверх к плате МК)                       │
└────────────────────────────────────────────────────────────────┘
            ↕ верхний header 2×N
┌─ Плата ВВ (эта плата) ───────────────────────────────────────┐
│  MAX1847 → IRLML0060 → ATB322524 → ×8 CW → −HV               │
│                              │                                 │
│                        шиль. кабель → плата делителя           │
└────────────────────────────────────────────────────────────────┘
            ↕ нижний header 2×N
┌─ USB/питание (снизу) ────────────────────────────────────────┐
│  +5V_HV — силовой, ≤ 200 мА                                    │
│  +5V_A, +3.3V_A, +3.3V_D, −5V_A, GND, UART, LED, SWD, ...   │
└────────────────────────────────────────────────────────────────┘
```

## 1. Питание +5V_HV

Приходит с USB/Power board через шину **+5V_HV** нижнего header'а.  
Bulk-фильтр (L103 100мкГн + C115 47мкФ) **находится на USB/Power board** — перед header'ом, чтобы помехи MAX1847 @ 252 кГц не попадали в +5V_USB шину.

Локальный bypass на HV board:
```
+5V_HV ─┬─ C205 100нФ X7R ── GND   (у MAX1847 IN pin 15)
         ├─ C207 47мкФ X5R  ── GND   (bulk, у T201 pin 1)
         └─ C208 100нФ X7R ── GND   (ВЧ развязка, у T201 pin 1)
```
C207+C208 стоят прямо перед pin 1 T201 — компенсируют паразитную индуктивность header'а при пиковых токах переключения.

Локальный LDO (+3.3V_local) **отсутствует** — убран за ненадобностью. TL431 (Vref_2.5В) питается напрямую от +5V_HV.

## 2. MAX1847EEE+ — контроллер ВВ

**Корпус:** QSOP-16

| Пин | Функция | Подключение |
|---|---|---|
| IN (15) | Вход питания | +5V_HV |
| VL (2) | Внутренний LDO ~4.25В | Развязка C203 0.47мкФ к GND; POL соединён с VL |
| PGND (12) | Силовая земля | GND |
| GND (10,11) | Сигнальная земля | GND |
| GATE / EXT (14) | Затвор MOSFET | → R206 10Ом → Q201 IRLML0060 Gate |
| CS (13) | Датчик тока | узел Source Q201; R205 (0.1Ом) к GND; параллельно C206 100пФ X7R |
| FREQ (3) | Задание частоты | R202 180кОм к GND |
| COMP (4) | Компенсация петли | R201 1МОм → C202 33нФ → GND (последовательно); **+ C201 22пФ C0G COMP→GND** (поставлен 2026-09-20, см. §12) |
| REF (5) | Опорное 1.25В | Развязка C204 0.1мкФ к GND (вых., не нагружать) |
| FB (6) | Обратная связь | ← R207/R209–R217 (10×100МОм от CW_out) + R208 (2.2МОм от HV_CONTROL) |
| SHDN (8) | Отключение (LOW=выкл) | ← R204 10кОм (от MCU HV_ENABLE); R203 100кОм к GND |
| POL (1) | Полярность N-ch | → VL (pin 2) |
| SYNC (16) | Синхронизация | GND (не используется) |

**Частота переключения:**

Задаётся только резистором R202 по формуле даташита:
```
T = 5.21×10⁻⁷ + 1.92×10⁻¹¹ × R202 − 4.86×10⁻¹⁹ × R202²   (R202 в Омах)
f_sw = 1 / T
```
При R202 = 180 кОм (180000 Ом):  T ≈ 3.96 мкс → **f_sw ≈ 252 кГц**

**HV_ENABLE (прямое подключение от MCU, активный HIGH):**
```
MCU HV_ENABLE (PB10) ── R204 10кОм ── SHDN (pin 8)
                                            │
                                        R203 100кОм
                                            │
                                           GND
```
- MCU HV_ENABLE = **HIGH (3.3В)** → SHDN = HIGH → MAX1847 работает → HV включён
- MCU HV_ENABLE = LOW / floating → SHDN подтянут к GND через R203 → MAX1847 остановлен → **HV = 0В**

Безопасное состояние по умолчанию: при сбросе или отсутствии команды MCU — HV выключено.
R204 (10кОм) защищает GPIO MCU от помех с HV-платы. При V_SHDN = 3.3В > V_IH ≈ 3В (0.7×VL) — порог надёжно пройден.

## 3. Первичный контур: IRLML0060 + ATB322524

### IRLML0060 — силовой ключ
- N-MOSFET, SOT-23 (1 — G, 2 — S, 3 — D, как прежний IRLML0040), **Vds = 60 В**, Id = 2.7 А,
  RDS(on) 92 мОм макс @10 В / 116 мОм макс @4.5 В, VGS(th) 1.0–2.5 В, Qg 2.5 нК, C_oss 37 пФ, tf 4.2 нс
  (`docs/refs/IRLML0060.pdf`, Infineon). Заменил IRLML0040 (40 В) 2026-09-19 — см. бюджет выброса ниже.
- Затвор ← MAX1847 GATE
- Исток → R205 (0.1Ом) → PGND (датчик тока для CS MAX1847)
- Сток → T201 pin 4 (конец первичной обмотки)

**Паразитные эффекты IRLML0060 при 252 кГц:**

| Эффект | Параметр | Последствие | Решение |
|--------|----------|-------------|---------|
| Выброс на Drain при выключении | L_lk=0.4мкГн + C_oss=37пФ | пик 38.8 В типично, 43–45 В в худшем случае | Снаббер BAS516+C209+2×BZT52C18 + ключ на **60 В** (IRLML0060): запас ≥15 В |
| Эффект Миллера (C_gd ≈ 16пФ) | При нарастании V_drain ток через C_gd подзаряжает затвор обратно | Замедляет выключение, увеличивает потери переключения | R206=10Ом ограничивает скорость и контролирует dV/dt |
| Потери в C_oss | ½×37пФ×36²×252кГц ≈ 6мВт | Нагрев транзистора | Пренебрежимо мал |
| Осцилляция затвора | Паразитная индуктивность трасс PCB + C_gd → ВЧ-звон на Gate | Ложные включения, нестабильность | R206=10Ом давит осцилляцию; минимальная длина трассы Gate |

**Снаббер — детальная работа:**

При выключении Q201 ток первичной обмотки (через L_lk) не может оборваться мгновенно. V_drain начинает расти:
1. BAS516 открывается (Анод = Drain, потенциал растёт выше уровня катода)
2. Ток втекает в C209 (10нФ) — демпфирует звон, ограничивает скорость нарастания dV/dt
3. Когда V_drain достигает ~36В — открываются D202+D203 (2×BZT52C18 последовательно = 36В)
4. Избыточная энергия рассеивается в зенерах — V_drain зафиксировано на ~36В

**Бюджет выброса на стоке (расчёт 2026-09-19).** «36 В» — только номинал двух стабилитронов при 25 °C; к пику
прибавляется прямое падение BAS516 (напряжения диода и стабилитронов складываются — так и задумано референсом):

| слагаемое | типично | худший случай |
|---|---|---|
| пробой 2×BZT52C18 (16.8–19.1 В каждый, ТКН ≈ +0.09 %/°C) | 36.0 В | 38.2 В; +1.5 В при 70 °C |
| + VF BAS516 на пиковом токе 0.8–1.0 А | 1.4 В | 2.0 В |
| + подзаряд C209 за импульс (L_lk·I²/2 в 10 нФ) | 0.6 В | 0.9 В |
| + L·dI/dt петли «сток → D201 → C209 → земля → исток» (6–10 нГн, фронт 4–6 нс) | 0.8 В | 2.5 В |
| **пик на стоке** | **38.8 В** | **43.6 В (25 °C) / 45.1 В (70 °C)** |

С прежним IRLML0040 (40 В, лавина НЕ нормирована) запас был ~+1 В типично и отрицательный в худшем случае.
**Решение: Q201 = IRLML0060 (60 В), та же посадка SOT-23** — запас ≥15 В, снаббер без изменений.
Снаббер всё равно держать **максимально близко к Drain Q201 и T201 pin4** (слагаемое L·dI/dt).
На стенде: осциллограф на стоке при полном ВВ под нагрузкой делителя, щуп с короткой пружиной на землю.

### ATB322524-0110-T000 (TDK) — трансформатор
| Параметр | Значение |
|---|---|
| Производитель | TDK |
| Корпус | SMD 3.2×2.5×2.4 мм (1210/JIS) |
| Коэффициент трансформации | 1 : 10.2 |
| Индуктивность первичной | 7.0 ± 20% мкГн @ 100кГц |
| DCR первичной | 0.5 Ом макс |
| DCR вторичной | 60 Ом макс |
| Индуктивность рассеяния | 0.4 мкГн макс |
| Напряжение изоляции | 500 В rms |
| Номинальный ток | 0.7 А rms |

**Подключение:**
```
+5V_HV ─── T201 pin 1 (начало первичной обмотки, dot)
            T201 pin 4 (конец первичной) ─── IRLML0060 Drain ─── Анод D201 (BAS516)
            T201 pin 2 (начало вторичной, dot) ─── GND
            T201 pin 3 (конец вторичной) ─── C210 1нФ (первый конденсатор CW умножителя)
```

**Полярность вторичной обмотки:**
- Q201 включён: pin3 уходит в плюс (+94В), pin2 = GND → конденсаторы CW заряжаются
- Q201 выключён (флайбэк): pin3 уходит в минус → BAV23S умножителя проводят → −HV нарастает

### Снаббер первичного контура (RC + zener, по схеме референса)
```
T201 pin4 / Q201 Drain ─── D201 (BAS516) Анод
                            D201 Катод ─┬─ C209 10нФ ─── GND
                                        ├─ D202 (BZT52C18) Катод
                                             D202 Анод ─── D203 (BZT52C18) Катод
                                                           D203 Анод ─── GND
```
- **D201 BAS516** (SOD-523): быстрый диод, пропускает бросок Drain в снаббер
- **C209 10нФ**: демпфирует высокочастотный звон.
  🔴 **Поставить на 100 В (0805), сейчас в BOM 50 В** (`CC0603KRX7R9BB103`, код `9BB` = 50 В).
  Узел снаббера сидит на **35.7 В постоянно** (модель), пики 38 В типично и 43–45 В в худшем случае:
  запас всего 1.1–1.4× при норме ≥2×, а X7R при 72 % от номинала теряет больше половины ёмкости
  (10 нФ → 3–5 нФ), отчего снаббер жёстче и выброс на стоке выше расчётного.
- **D202 + D203** (два BZT52C18, SOD-123, последовательно): суммарный зенер 36В → ограничивают V_drain до ~36В
- Пик на стоке 38.8 В типично / до ~45 В в худшем случае (см. бюджет выше) → ключ IRLML0060 на **60 В**

**Датчик тока Q201:**
```
Q201 Source ─┬─ CS (pin 13 MAX1847)
             ├─ R205 0.1Ом ─── GND
             └─ C206 100пФ ─── GND   (фильтр помех CS, параллельно R205)
```

**Рабочий цикл** (уточнено моделированием 2026-09-20, `simulation/hv_loop/`):
Преобразователь работает в прерывистом режиме (DCM), умножителю важен **размах** на вторичке:
- прямой ход (Q201 открыт): pin3 = −Vвх × Ns/Np ≈ **−51 В** (задан входным напряжением);
- обратный ход (флайбэк): pin3 = +V_r × Ns/Np, где V_r — отражённое напряжение на первичке;
  сток при этом поднимается до Vвх + V_r;
- размах V_pp = 51 В + V_r × 10.2, выход умножителя ≈ 4 × V_pp минус просадка (4 ступени, см. §4).

| выход | нужный V_pp | V_r | пик на стоке | КПД (модель) | рассеивание в стабилитронах |
|---|---|---|---|---|---|
| −1200 В | ≈ 310 В | 25 В | ≈ 34 В | 83 % | 15 мВт |
| −1500 В | ≈ 385 В | 33 В | **≈ 37 В — уровень снаббера** | 61 % | 140 мВт |

⚠ Выше ~1300 В полка флайбэка упирается в снаббер (2×BZT52C18 + VF BAS516 ≈ 36–37 В), и часть энергии
уходит в стабилитроны вместо умножителя: КПД падает, потребление растёт (48 мА при 1200 В, 103 мА при 1500 В).
Рабочая зона ФЭУ (≈ 500…1200 В) от этого не страдает; 1500 В — только край диапазона.

### Паразитные эффекты трансформатора при 252 кГц

**1. Индуктивность рассеяния (L_lk = 0.4 мкГн макс)**
Часть энергии, накопленной в первичке, не передаётся во вторичную обмотку — она сосредоточена в поле рассеяния. При выключении Q201 ток через L_lk не может оборваться мгновенно — возникает выброс напряжения на Drain. Именно L_lk является главной причиной применения снаббера (BAS516 + C209 + 2×BZT52C18). Рекомендация по PCB: минимальная площадь петли T201–Q201–C207/C205 для уменьшения паразитной индуктивности трасс, усиливающей выброс.

**2. Межобмоточная ёмкость (C_winding)**
Первичная и вторичная обмотки ёмкостно связаны. Быстрые перепады dV/dt на Drain при переключении (252 кГц) просачиваются через эту ёмкость прямо в высоковольтный выход CW умножителя, инжектируя высокочастотный шум. Это дополнительное обоснование необходимости 3-каскадного RC-фильтра после CW (раздел 5): он подавляет не только пульсации умножителя, но и этот кондуктивный шум.

**3. Потери в сердечнике**
При 252 кГц в феррите присутствуют два вида потерь:
- Гистерезисные (∝ f): перемагничивание сердечника за каждый цикл
- Вихревые токи (∝ f²): индуцированные токи в сердечнике

ATB322524 — ферритовый трансформатор, оптимизированный для диапазона 100 кГц–1 МГц. Частота 252 кГц находится в его нормальной рабочей точке.

**4. Скин-эффект в обмотках**
При 252 кГц глубина проникновения тока в медь:
```
δ = 66 / √252000 ≈ 0.13 мм
```
Ток вытесняется к поверхности проводника → эффективное AC-сопротивление обмоток превышает DCR (0.5 Ом первичка / 60 Ом вторичка). Вызывает небольшой дополнительный нагрев трансформатора, при токе 115 мА пренебрежимо мал.

**Итог:** все паразитные эффекты учтены в схемотехнике — снаббер (L_lk), RC-фильтр (C_winding), выбор компонента (потери в сердечнике), тепловой режим (скин-эффект).

### BAV23S в CW умножителе при 252 кГц

BAV23S используется как один диод (2 последовательных диода = 500В обратного напряжения, pin3 = NC).

- **Обратное напряжение на пару:** 2 × V_пик ≈ 375В < 500В ✓
- **Время обратного восстановления:** t_rr ≈ 50нс; доля периода: 50нс / 3970нс ≈ 1.3% — ток обратного восстановления пренебрежимо мал
- **Ток через конденсатор 1нФ:** I ≈ C × ΔV/Δt ≈ 90 мкА — потери на восстановление незначительны
- **Вывод:** диоды справляются с частотой 252 кГц без ограничений ✓

## 4. Вторичный контур: CW умножитель × 4 ступени

Вторичная обмотка T201 (pin3) подключается **напрямую** к первому конденсатору C210 CW умножителя — отдельный выпрямительный диод на вторичной стороне **отсутствует**. Функцию выпрямления выполняют диоды BAV23S внутри умножителя.

### Умножитель Кокрофта-Уолтона, 4 ступени

⛔ **Исправлено 2026-09-20 (сверено по `pcb/gamma_spectrometer.net`): ступеней ЧЕТЫРЕ, а не восемь.**
Оба диода внутри BAV23S включены последовательно (вывод 3 не подключён), то есть **один корпус = один
диод на 500 В**, а не две ступени. 8 корпусов + 8 конденсаторов = 4 ступени (2n диодов при n = 4).

**Конденсаторы:** 8 × **1нФ C0G 500В 0805** (C210–C217)
- толкающая колонка: T201.3 –C210– a1 –C212– a2 –C214– a3 –C216– a4
- сглаживающая: GND –C211– b1 –C213– b2 –C215– b3 –C217– b4 = CW_out

**Диоды:** 8 × **BAV23S** (SOT-23-3; два диода в серии = 500 В, 200 мА)
D205 a1→GND, D204 b1→a1, D207 a2→b1, D206 b2→a2, D209 a3→b2, D208 b3→a3, D211 a4→b3, D210 b4→a4.

**Расчёт:**
```
V_out = n × V_pp = 4 × V_pp,  V_pp = 51В + V_r × 10.2   (см. §3)
−1200В → V_pp ≈ 310В ;  −1500В → V_pp ≈ 385В
```
⚠ **Запас по напряжению у C210–C217 (1 нФ C0G 500 В) тоже скромный:** каждый конденсатор ступени
видит полный размах V_pp = 310 В при уставке 1200 В и 385 В при 1500 В, то есть 62…77 % от номинала.
У C0G ёмкость от смещения не падает, вопрос только в пробое. Варианты: держать уставку ≤1200 В
(рабочая зона ФЭУ и так ниже) либо ставить 1 кВ. Прежняя оценка «189 В» шла из ошибочных 8 ступеней.

Обратное напряжение на каждом корпусе BAV23S = V_pp ≈ 310…385 В < 500 В ✓ (запас скромный;
на отдельный диод внутри корпуса приходится половина только при равном делении — выравнивающих
резисторов нет, это штатная практика для BAV23S, но при замене диодов проверить).
Толкающая колонка качается на полный V_pp с частотой 252 кГц — это главный источник наводок
на плате (см. §12 про цепь обратной связи).

**Выходные накопительные конденсаторы:**
```
CW_out ─── C13a201─C13b201 (2× 0.1мкФ/1кВ в серии = 50нФ/2кВ) ─── GND
       └── C14a201─C14b201 (2× 0.1мкФ/1кВ в серии = 50нФ/2кВ) ─── GND
```
Тип: **C1812X104K102T (Holy Stone)** — 0.1мкФ X7R 1кВ, корпус 1812. По 2 штуки последовательно на каждую позицию (C13a201+C13b201 = одна позиция C13a201/C13b201).
⚠ Рабочее напряжение узла = полное выходное ВВ (~1500В). Только ВВ-исполнение ≥2кВ. Типовые 25В/100В керамика **недопустимы**.

## 5. RC-фильтры выхода

Три каскада RC-фильтрации для подавления пульсаций умножителя:

```
CW_out ─── R220 100кОм ─── node1 ─── R231 100кОм ─── node2 ─── R232 100кОм ───┬─── −HV_out
                    │                         │                           │      │
  C15a201─C15b201 2×0.1мкФ/1кВ  C16a201─C16b201 2×0.1мкФ/1кВ  C17a201─C17b201 2×0.1мкФ/1кВ  R233 10Ом
                    │                         │                           │      │
                   GND                       GND                         GND  C18a201─C18b201 2×220пФ C0G/1кВ = 110пФ/2кВ
                                                                               │
                                                                              GND
```
ВЧ фильтр R233+C18a201/C18b201 стоит **на выходе** (−HV_out), прямо перед нагрузкой (ФЭУ).
Напряжение на C18a201/C18b201 ≈ 1442В → 2× CC1206JKNPOCBN221 (220пФ C0G 1кВ 1206) последовательно = **110пФ / 2кВ**.
C0G обязателен: X7R при высоком DC-смещении теряет ёмкость, C0G стабилен.

Каждая позиция C15a/b201, C16a/b201, C17a/b201: **2× C1812X104K102T (Holy Stone) последовательно** (0.1мкФ / 1кВ X7R 1812):
- C_eff = 50нФ (0.1мкФ / 2), V_rating = 2кВ (1кВ × 2)
- Каждый конденсатор видит max 750В << 1кВ ✓
- DC-баланс без резисторов: для одинаковых керамических конденсаторов одной партии допустимо

**Постоянная времени:** RC = 100кОм × 50нФ = **5 мс** на каскад

**Падение напряжения на фильтре** (нагрузка ФЭУ 194 мкА + монитор 22 мкА):
216 мкА × 3 × 100кОм ≈ **50…58В** при полной нагрузке.

⛔ **Исправлено 2026-09-20: петля это НЕ компенсирует.** Обратная связь (R207/R209–R217) снимается
с **CW_out, то есть ДО фильтра** — все три резистора по 100 кОм находятся ВНЕ петли. Модель при 1200 В:

## 6. Управление: HV_CONTROL и обратная связь

MAX1847 содержит встроенный усилитель ошибки: регулирует скважность ШИМ так, чтобы **V_FB = 0В**. Внешний усилитель ошибки не нужен.

### Топология делителя FB

```
CW_out ── R207 ── R209 ── R210 ── R211 ── R212 ── R213 ── R214 ── R215 ── R216 ── R217 ── FB (pin 6)
          100М    100М    100М    100М    100М    100М    100М    100М    100М    100М       │
                              суммарно 1 ГОм                                           R208 2.2МОм
                                                                                    │
                                                                             [HV_CONTROL]
```

### Расчёт

Условие регулирования V_FB = 0В. На узле FB сходятся два тока:

```
V_CW / 1ГОм + V_CTRL / 2.2МОм = 0
V_HV = −V_CTRL × (1ГОм / 2.2МОм) = −V_CTRL × 454.5
```

| V_CTRL | V_HV на CW_out | −HV_out на ФЭУ (нагрузка 194 мкА) |
|---|---|---|
| 0 В | 0 В | 0 В |
| 1.1 В | −500 В | ≈ −479 В |
| 2.64 В | −1200 В | ≈ −1150 В |
| 3.3 В | −1500 В | ≈ −1437 В |

(разница — падение на RC-фильтре, который стоит вне петли, см. §5)

**HV_CONTROL:** PA8 (TIM1_CH1) PWM → RC-фильтр fc=160Гц → постоянное V_CTRL = 0…3.3В.

### Компоненты

| Ref | Номинал | Корпус | Назначение |
|---|---|---|---|
| R207, R209–R217 | 100МОм (×10) | 1206 | Верхнее плечо FB (суммарно 1ГОм) |
| R208 | 2.2МОм | 0402 | Нижнее плечо: задаёт коэффициент −454.5 |

Напряжение на каждом резисторе цепочки: 1500В / 10 = **150В << 200В** (макс. 1206) ✓

## 7. Мониторинг ВВ (HV_MONITOR)

Делитель: Vout− (0…−1500В) → 0…2.5В для MCU ADC (VREF = 2.5В).

```
−HV_out ─── R221–R230 (10 × 6.8МОм 1206 серия) ─── mon_node ─── R219 110кОм ─── катод TL431 (U202, 2.495В)
                                                        │
                                                HV_MONITOR ──── MCU ADC (PA0)
```

Буфер не нужен: R_th на mon_node = 68МОм ∥ 110кОм ≈ **110кОм**. MCU ADC справляется напрямую при времени выборки ≥ 247.5 цикла (требование: ~5.8мкс при ADC clock 42.5МГц).

**Расчёт делителя:**
- R221–R230 суммарно = 68 МОм, R219 = 110 кОм
- V_mon = Vref + (V_HV − Vref) × R219 / (R_chain + R219), где R_chain=68МОм, R219=110кОм
- V_HV = 0В:    V_mon = 2.5 + (0 − 2.5) × 110к/68.11М ≈ **2.496В** ✓ (≈2.5В)
- V_HV = −1500В: V_mon = 2.5 + (−1502.5) × 110к/68.11М ≈ **0.08В** ✓ (≈0В)
- Ток через делитель при 1500В: I = (1500В + 2.5В) / (68МОм + 110кОм) ≈ **22 мкА** (потребление HV цепью минимально)
- Каждый резистор 1206 (6.8МОм): 150В << 200В рабочих ✓

**Источник опорного 2.5В (Vref_2.5В) — TL431DBZ (U202):**
```
+5V_HV ─── R218 1.2кОм ─── Cathode (K)
                                  │
                            REF ──┤ (замкнут на K → V_K = 2.495В)
                                  │
                            C218 100нФ (на REF → GND)
                                 │
                                GND
TL431 Anode (A) ─── GND
```
- R218 задаёт ток катода: I_K = (5В − 2.5В) / 1.2кОм ≈ **2.1 мА** > 0.5 мА min ✓
- C218 (100нФ): стабилизирует TL431 против ВЧ-помех

**Прошивка:** канал PA0 (ADC2_IN1) — установить SampleTime = **247.5 cycles**.

## 11. Требования к PCB

- Зазор −HV/GNDA от любых трасс: ≥ 3 мм (правило 1 мм/500В)
- Резисторы R221–R230 (6.8 МОм 1206): расположить в цепочку, зазор ≥ 1 мм между корпусами
- R207 (100 МОм): максимально далеко от влажных зон, покрыть лаком
- Первичный контур (T201, Q201): компактная петля переключения, минимальная площадь; C205(100нФ) рядом с MAX1847 IN
- **Цепь обратной связи (R207, R209–R217, узел FB) — максимально далеко от толкающей колонки умножителя
  (a1…a4: узлы конденсаторов C210/C212/C214/C216), между ними земля.** Сейчас FB отстоит ≥ 11 мм,
  ближайший узел цепочки — 3.45 мм; наводка 1.4 фФ уже значима (§12). C201 (C_COMP2) — вплотную к выводу COMP
- CW умножитель: линейная цепочка от T201 pin3 к выходу, нарастающие зазоры к высоковольтному концу
- GNDA ↔ GND: соединять в одной точке (звёздная земля)
- TL431 (U202): близко к mon_node, C218 100нФ — максимально короткие трассы
- **Заливка силиконом** (вся плата после сборки и проверки):
  - Обеспечивает изоляцию ВВ узлов (−1500В) и влагозащиту
  - Заменяет лаковое покрытие — лак не нужен
  - Максимальная высота компонентов ограничена глубиной формы заливки
  - Перед заливкой: убедиться в отсутствии ERC/функциональных ошибок — демонтаж из силикона невозможен
  - Рекомендуемый силикон: ПТК Силагерм или аналог (диэлектрическая прочность ≥ 20 кВ/мм)

## 12. Пульсации, устойчивость петли и наводка на FB (моделирование 2026-09-20)

Модель: `simulation/hv_loop/` — переключательная модель LTspice (поведенческий MAX1847 по даташиту,
T201 с индуктивностью рассеяния, снаббер, умножитель по нетлисту, RC-фильтры, нагрузка делителем ФЭУ)
плюс матрица паразитных ёмкостей платы из FastCap по `.kicad_pcb`.

**Пульсации — с большим запасом:**

| узел | 500 В | 1200 В | 1500 В |
|---|---|---|---|
| CW_out | 22 мВ пп | 38 мВ пп | 45 мВ пп |
| −HV_out (после 3×RC) | единицы нВ | единицы нВ | единицы нВ |

Остаток ШИМ HV_CONTROL (100 кГц после двух звеньев RC) ≈ 13 мкВ — далеко за полосой петли.
Умножитель отдаёт заряд через цикл, то есть даёт составляющую на 126 кГц; на выход она не проходит.
Реальный уровень пульсаций на −HV_out будет задавать разводка, а не схема.

**Петля устойчива** (замер петлевого усиления на переключательной модели):

| ВВ | частота среза | запас по фазе |
|---|---|---|
| 500 В | ≈1.3 кГц | ≈100° |
| 1200 В | ≈2.7 кГц | ≈90° |
| 1500 В | ≈2.5 кГц | ≈93° |

Усиление на низких частотах ≈ 80 дБ. Петля однополюсная, звона нет.

**🔴 Наводка на FB — требует C_COMP2.**
Узел FB высокоомный (2.2 МОм), а толкающая колонка умножителя качается на 310…385 В при 252 кГц.
FastCap по плате: C(FB ↔ колонка A) = **1.4 фФ** типично (×2.75 для FR-4) и 2.2 фФ по верхней границе;
зазоры: сам FB ≥ 11 мм от колонки, ближайший узел цепочки 1 ГОм — 3.45 мм. Наводка на FB получается
**123…150 мВ размаха**. Усилитель ошибки на 252 кГц имеет усиление ×300 (R201‖Ro = 0.75 МОм), поэтому:

| вариант | COMP | пик тока Vcs | ВВ (уставка −1200 В) |
|---|---|---|---|
| без наводки | 16 мВ пп | 60.1 ± 0.7 мВ | −1199.6 В |
| реальная наводка, без C_COMP2 | **упор 3.0 В** | 42 ± 18 мВ | **−1191 В (−9 В)** |
| то же при уставке −1500 В | упор 3.5 В | упирается в предел тока 100 мВ | **−1491 В (−9 В)** |
| реальная наводка + C_COMP2 22 пФ | 765 мВ пп | 53.6 ± 17 мВ | **−1199.5 В** ✓ |

Без C_COMP2 петля упирается в потолок и ВВ проседает примерно на 9 В (≈ 5 % по усилению ФЭУ).
С C_COMP2 регулирование восстанавливается; остаётся автоколебание ~350 Гц амплитудой ±1.1 В на CW_out,
которое после RC-фильтров даёт ~4 мВ на выходе (0.003 % по усилению) — пренебрежимо.
