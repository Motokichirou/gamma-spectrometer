# Требования производителя (ПС-Электро) и сверка с нашим проектом

Источник: <https://pselectro.ru/zakaz-pechatnyh-plat/trebovania-k-proektu-pecatnoj-platy-40626/>
Сверка выполнена 2026-08-08 по `pcb/gamma_spectrometer/gamma_spectrometer.kicad_pcb`.

> Заказ плат идёт **на ПС-Электро**, не на JLCPCB. Все прежние оценки стоимости и
> правила DFM под JLCPCB в остальных доках устарели.

## 1. Сводка: что не проходит

| # | Требование ПС-Электро | У нас сейчас | Статус |
|---|---|---|---|
| 1 | Поясок металлизированного отверстия **≥ 0.25 мм** на наружных слоях | **0.15 мм** на всех **155 виа** (пад Ø0.60 / сверло Ø0.30) | 🔴 **не проходит** |
| 2 | Высота символов шелкографии **≥ 1.3 мм** (нечитаемое удаляется) | **234 надписи** высотой 0.8 / 1.0 / 1.2 мм — то есть *все* | 🔴 **не проходит** |
| 3 | Сверло из номинального ряда | **Ø2.75 мм** ×12 (стойки M2.5) — в ряду нет: есть 2.7 и 2.8 | 🟡 округлят сами, лучше задать явно |
| 4 | Отверстия **> 4.5 мм — только фрезеровкой** | **Ø5.0 мм** ×1 (`H_HV301`, проход провода −ВВ) | 🟡 указать в заказе как фрезеровку |
| 5 | Зазор медь → край платы: 0.30 мм (кл. А) / 0.25 мм (кл. В) при фрезеровке | минимум **2.219 мм** по всей панели | ✅ с запасом ×7 |
| 6 | Ширина линии заливки полигона ≥ 0.2 мм | 0.2 / 0.25 мм | ✅ на границе |
| 7 | Ширина линий шелкографии ≥ 0.15 мм | 0.12 мм в наших футпринтах | 🟡 проверить перед выпуском |
| 8 | Типов свёрл: оптимум ≤ 9, свыше 12 — надбавка | **8 типов** | ✅ |
| 9 | Платы < 25×25 мм — только групповой заготовкой | Ø45 мм = 1590 мм² каждая | ✅ ограничение не действует |
| 10 | Мин. радиус контура 0.75 мм (фреза 1.5) | контуры — окружности Ø45 | ✅ |

### Как чинить 1 и 2

**Пояски виа.** Увеличить пад виа Ø0.60 → **Ø0.80** при сверле Ø0.30: поясок станет
ровно 0.25 мм. Правится в Файл → Параметры платы → Установки заготовки, затем
перетрассировка не нужна — только перезаливка зон. Альтернатива: сверло 0.3 → 0.25
(есть в доп. ряду) при паде 0.75, но 0.25 у них не в основном ряду — хуже.

**Шелкография.** Норма 1.3 мм на плате Ø45 со 177 компонентами физически не влезет,
если подписывать всё. Варианты:
- подписывать только разъёмы, полярность и ключевые элементы, высотой 1.3 мм;
- остальные обозначения убрать с шелкографии и оставить на `F.Fab` (на плату не идёт,
  но останется в сборочном чертеже);
- если нужны все позиционные обозначения — заказывать **плёночную** маркировку и
  согласовывать 1.0 мм отдельно.

Решение принимать перед выпуском Gerber. Сейчас в проекте ~400 замечаний DRC по
шелкографии (наложения на пады) — их чистка и это решение делаются одним заходом.

## 2. Полные требования (выписка)

### Файлы
- Топология: **Gerber RS-274X**, сверловка: **Excellon**
- Координаты не более 1430 мм (56300 mils) по X и Y

### Отверстия
Номинальный ряд, мм: 0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.3, 1.4, 1.5,
1.6, 1.7, 1.8, 2.0, 2.1, 2.2, 2.3, 2.4, 2.5, 2.6, 2.7, 2.8, 3.0; дополнительно
3.1…4.5 с шагом 0.1, а также 0.25, 0.35, 0.85, 0.95.

- **> 4.5 мм — фрезеровкой**
- Слотовые свёрла: 0.8, 1.0, 1.2, 1.5 мм
- Оптимально до **9** типов свёрл; свыше **12** — повышающий коэффициент
- Поясок ≥ **0.25 мм** на наружных слоях
- Вырез вокруг НЕметаллизированного отверстия в полигоне ≥ **0.3 мм** (внутр. слои МСП ≥ 0.4 мм)

### Паяльная маска
- Зелёная жидкая по умолчанию
- Мин. зазор между окнами маски **100 мкм**; цветная/плёночная ≥ **150 мкм**
- 75 мкм — по согласованию, **+30 % стоимости**
- Переходные отверстия ≥ 1.5 мм вскрываются на 0.1 мм от диаметра сверла

### Маркировка
- Ширина линий ≥ **0.15 мм**
- Высота символов ≥ **1.3 мм** (нечитаемое **удаляется**)
- На слоях топологии ≥ 1.7 мм

### Контур
- Допуск h12 ГОСТ 25347-82 (для плат ≥ 25×25 мм)
- Мин. радиус скругления 0.75 мм (фреза 1.5 мм); по умолчанию 1.25 мм (фреза 2.5 мм)
- Зазор медь–край: фрезеровка **0.30 мм** (кл. А) / **0.25 мм** (кл. В); скрайбирование
  **0.50 мм**; алюминий 0.70 мм

### Полигоны
- Векторные, ширина линии заливки ≥ 0.2 мм
- Минимальный элемент 0.3 мм (оптимум 0.4 мм внутри)

### Групповая заготовка
- Платы < 25×25 мм или < 625 мм² — только групповой заготовкой
- Расстояние между платами: **2.3 мм** при фрезеровке, встык при скрайбировании

### Прочее
- Коробление: 1.5 % (штыревой монтаж), 0.75 % (поверхностный)
- Изготовитель вправе менять ширину проводников и высоту диэлектрика **на ±25 %**
  без согласования — критичные по импедансу цепи оговаривать отдельно
- Электроконтроль обязателен для МСП и плат повышенной сложности; платы < 0.5 мм — только AOI

## 3. Что дослать вместе с Gerber

- Указать **Ø5.0 мм (`H_HV301`) как фрезеровку**, а не сверление
- Оговорить, что плата несёт **до −1500 В**: зазоры заданы правилами
  `gamma_spectrometer.kicad_dru` (3 мм/кВ, 49 правил) и уменьшать их нельзя
- Оговорить заливку силиконом после сборки (влияет на выбор маски)
- 4 платы Ø45 идут **групповой заготовкой**; межплатные цанговые пины должны быть
  соосны — контур резать по окружностям
