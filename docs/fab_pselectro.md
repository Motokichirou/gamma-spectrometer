## 0. Параметры заказа (оформлен 2026-09-29)

Полный текст требований для завода — `pcb/gamma_spectrometer/gerbers/readme.txt`,
он кладётся в архив вместе с герберами.

| поле бланка | что указано |
|---|---|
| размер X × Y | **187.5 × 45 мм** (вся заготовка) |
| вырезы/окна | **3 шт, 3.35 × 8.73 мм**, суммарная длина реза **73 мм** |
| конструктив | ДПП, 2 слоя |
| материал / толщина / фольга | **FR-4, 1.5 мм, 35/35 мкм** = типовой конструктив `2/15/35/FR` |
| паяльная маска | LPI, зелёная, **с двух сторон**; окна = площадкам (расширение 0); переходные **не вскрывать** |
| маркировка | **нет**, слои шелкографии в комплект не входят |
| финишное покрытие | **HASL** (ПОС-63) с выравниванием |
| мехобработка контура | **фрезеровка**, скрайбирования и V-паза нет; окна фрезой **≤2.0 мм** |
| сверловка | диаметры **конечные**, после металлизации |
| электротестирование | **да**, netlist не прилагать — цепи извлекать из герберов |
| контроль импеданса | **нет** |
| сложность плат | строка **«больше или равно 0.15 / 0.15 / d 0.3»** |
| количество | **2 комплекта** (цена: наладка ≈2196 ₽ + ≈482 ₽ за комплект) |

**Почему 1.5 мм, а не 1.6.** Типовые конструктивы ДПП у завода — 1.0, 1.5 и 2.0 мм,
и только они изготавливаются **от одной штуки**. Нетиповой конструктив требует заказа,
кратного заготовке **6 дм²**, а наша панель 0.84 дм² — пришлось бы брать ~7 копий.
На конструкцию 1.5 мм не влияет: высоту стека задают стойки М2.5, а не толщина плат.

**Почему не самая простая строка сложности.** В строке «от 0.2 / 0.2 / d 0.4 и больше»
требуется отверстие ≥0.4, а у нас 210 виа со сверлом 0.3. Рассверлить до 0.4 можно
(геометрия выдержит, минимум между отверстиями остаётся 0.40 мм), но ободок станет ровно
0.200 — а при компенсации на металлизацию просядет до ~0.175, то есть ниже порога той же
строки. Оставили 0.3 с ободком 0.25.

**Почему маска без расширения.** Стандарт завода 0.05 мм на сторону. С ним перемычка
маски между окнами на `U302` (**LQFP-48**, шаг 0.5) и `U103` (QFN-20) упала бы с 0.20 до
0.10 мм — это их «предельный» параметр. С нулевым расширением остаётся 0.20–0.25.
Шаг выводов от смены корпуса не изменился, так что цифра та же: пад 0.3 при шаге 0.5 ⇒ 0.2 мм.

**Виа в падах.** Пересчёт 2026-10-08 по новой разводке: **31 из 210** виа попадают внутрь
контактных площадок — USB 6, ВВ 8, делитель 11, МК 6. Вскрытие маски там приходит от
площадки. Заполнение компаундом не заказывали (решение 2026-09-29): при ручной пайке просто
добавить припоя.

| плата | где |
|---|---|
| USB | `C108.2`, `C115.1`, `R101.1`, `R_CC102.2`, `U102.2`, `U104.2` |
| ВВ | `C16b201.2`, `C17b201.2`, `C201.1`, `C202.2`, `C203.1`, `C217.2`, `C218.1`, `R202.1` |
| МК | `C316.1`, `R302.2`, `R308.2`, `R311.1`, `R311.2`, `Y301.4` |
| делитель | `C409.2`, `C413.1`, `D401.1`, `D402.2`, `Q402.3`, `R407.2`, `R408.2`, `R409.2`, `R410.2`, `U402.3`, `U402.4` |

Самые чувствительные — `Y301.4` (кварц) и `C201.1` (C_COMP2 петли ВВ). На плате МК две виа
в падах `R311` поставлены намеренно: ими лечился оторванный остров заливки под нижним плечом
делителя PGA (см. `CLAUDE.md`, п. 2).

### Заготовка из четырёх плат (2026-09-29)

Четыре круглые платы Ø45 собраны в **одну заготовку 187.5 × 45 мм** с перемычками
под разлом. Скрипт — `pcb/panelize.py` (запуск `python pcb/panelize.py --apply`,
без ключа пишет копию рядом и проект не трогает).

**Что сделано**

| | |
|---|---|
| Шаг плат | 70 → **47.5 мм**, зазор между контурами **2.5 мм** — под стандартную фрезу завода 2.5 мм |
| Центры | USB 100, ВВ **147.5**, МК **195**, делитель **242.5** (перенос только по X, без поворотов) |
| Контур | 4 окружности заменены на **12 дуг** + **12 прямых** сторон перемычек |
| Перемычки | **6 штук**, по две на стык, под ±15° от линии центров; ширина 3 мм по дуге, длина 4.0 мм |
| Отверстия разлома | **36 шт Ø0.6 NPTH**, по 3 в ряд с шагом 1 мм, по ряду на каждом конце перемычки. Центры вынесены на **0.2 мм наружу** контура — тогда до меди остаётся 0.402 мм при норме выреза 0.3 |
| Зоны запрета | **6 штук** по перемычкам. Контуры зон GND нарисованы крупнее платы (их обрезал круглый Edge.Cuts) — без запрета перезаливка залила бы медь прямо в перемычки и на отверстия разлома. Запрет заходит на 0.526 мм внутрь платы против отступа меди 0.5 мм, то есть существующую заливку почти не трогает |
| Стойки | сверло **2.75 → 2.8 мм** (в номинальном ряду), поясок стал 1.10 мм |
| Проход −ВВ `H_HV301` | **Ø5.0 → Ø4.5**: не нужна фрезеровка, вырез в полигоне стал 0.50 мм при норме 0.3, провод Ø3 проходит с зазором 0.75 мм по радиусу. Футпринт переименован в `HOLE_HV_WIRE_D4.5` |

**Сверловка теперь целиком в номинальном ряду завода, 8 типов:**
Ø0.30 ×225 (виа) · Ø0.50 ×4 · Ø0.60 ×38 NPTH (2 старых + 36 разлома) · Ø0.80 ×4 (пазы) ·
Ø1.00 ×11 · Ø1.50 ×44 · Ø2.80 ×12 · Ø4.50 ×1 NPTH.

**Проверки после сборки заготовки**

- Геометрия каждой платы относительно своего центра совпадает с исходной **до нуля**
  (USB 8896 точек, ВВ 8094, МК 12140, делитель 5088) — перенос ничего не потерял и не исказил.
- DRC: зазоры **3** (те же принятые ВВ-правила), «не соединено» **27** — как было.
  Новых типов нарушений нет, кроме шести `items_not_allowed` (см. ниже).
- Медь → контур заготовки **0.501 мм** (норма 0.30); отверстия разлома → медь **0.402 мм** (норма 0.30);
  все 36 отверстий накрыты зонами запрета с запасом 0.308 мм.
- Радиусы всех 12 дуг ровно 22.500, центры точно в новых позициях.

**Что обязательно сделать в KiCad перед выпуском**

1. **Перезалить зоны** (`B`). Пока этого нет, DRC показывает **6 `items_not_allowed`** —
   это старая заливка, наползающая на зоны запрета перемычек. После перезаливки уйдут.
2. Класс цепей `Default`: виа **0.6 → 0.8** (существующие 225 правильные, новые были бы нет).
3. Перевыгрузить герберы и сверловку.

**Остаточные замечания, к изготовлению не относятся:** `lib_footprint_mismatch` ×2 —
`J101` (пады правились в плате) и `T201` (пады и графика с библиотекой совпадают
побайтово, различие в метаданных); `track_dangling` ×1 — обрубок `+3.3V_D` 0.56 мм
на USB; `courtyards_overlap` ×43; шелкография в выгрузку не идёт.

**Осталось по пояску:** два виа на плате делителя всё ещё 0.60/0.30 —
**(330.000, −100.500)** и **(329.250, −104.500)**, цепь №3.
И в классе цепей `Default` «диаметр перех. отв.» по-прежнему 0.6 — новые виа
будут неправильными, поменять на 0.8.

**47 нарушений netclass** — это виа, подошедшие к дорожкам и падам на 0.10…0.19 мм
вместо 0.20. Распределение: 0.10 мм — 24 случая, 0.11 — 9, 0.13/0.14/0.15 — по 1,
0.18 — 10, 0.19 — 1. Снижение нормы зазора не спасает: до 0.15 мм убирает только 11,
до 0.10 — все, но 0.10 мм это класс 5 и на ЛУТ невоспроизводимо. Значит 26 виа надо
разводить локально (сдвинуть виа либо отодвинуть дорожку).

**7 ВВ-правил**: пять приняты 2026-09-21 (`C212`, `C211`, `C210`, `C18a201`, `C17a201`),
**два новых** от роста пада — `HV Net-(R227-Pad2) -> GND` (требуется 1.300, факт 1.225)

### Что править перед выпуском

1. **Пояски виа.** Пад Ø0.60 → **Ø0.80** при сверле Ø0.30: поясок станет ровно 0.25 мм.
   Файл → Параметры платы → Установки заготовки. Перетрассировка не нужна, но **зоны
   перезалить и DRC прогнать заново**: виа 226 штук, пад растёт на 0.2 мм, часть зазоров
   может поджаться — особенно на плате ВВ, где свои правила 3 мм/кВ.
2. **Пады `J101`.** Овал 1.20 → **1.30** по узкой стороне при слоте 0.80 даёт поясок 0.25.
   Правится в проектной копии футпринта. Альтернатива — согласовать 0.20 мм с заводом.
3. **Удалить виа** в точке (137.5, −118) — оно ничему не принадлежит (`net 0`).
4. Перевыгрузить герберы и сверловку после правок.

### Замечания вне требований завода (в герберах уже есть)

- **5 нарушений наших же ВВ-зазоров** (3 мм/кВ): `C210`/`C211`/`C212-Pad2`, `C17a201`,
  `C18a201`. Приняты пользователем 2026-09-21 — заводу они безразличны, это наш запас
  по пробою.
- **DRC видит 2 «не соединено» внутри одной платы** — зоны GND: на USB в (100, −76.5)
  и на ВВ в (149.25, −86.5). Остальные 25 «не соединено» — межплатные, это норма
  (мост = цанг-пины в стеке), проверено по координатам. Эти два стоит посмотреть
  в редакторе: возможен островок земли, отрезанный от основного полигона.
- `starved_thermal` на `C202` (1 мостик терморазгрузки вместо 2) — пайка чуть сложнее,
  на изготовление не влияет.

## 2. Полные требования (выписка)

### Файлы
- Топология: **Gerber RS-274X**, сверловка: **Excellon**
- Координаты не более 1430 мм (56300 mils) по X и Y

### Отверстия
Номинальный ряд, мм: 0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.3, 1.4, 1.5,
1.6, 1.7, 1.8, 2.0, 2.1, 2.2, 2.3, 2.4, 2.5, 2.6, 2.7, 2.8, 3.0; дополнительно
3.1…4.5 с шагом 0.1, а также 0.25, 0.35, 0.85, 0.95.

- **> 4.5 мм — фрезеровкой**
- Слотовые свёрла: 0.8, 1.0, 1.2, 1.5 мм
- Оптимально до **9** типов свёрл; свыше **12** — повышающий коэффициент
- Поясок ≥ **0.25 мм** на наружных слоях
- Вырез вокруг НЕметаллизированного отверстия в полигоне ≥ **0.3 мм** (внутр. слои МСП ≥ 0.4 мм)

### Паяльная маска
- Зелёная жидкая по умолчанию
- Мин. зазор между окнами маски **100 мкм**; цветная/плёночная ≥ **150 мкм**
- 75 мкм — по согласованию, **+30 % стоимости**
- Переходные отверстия ≥ 1.5 мм вскрываются на 0.1 мм от диаметра сверла

### Маркировка
- Ширина линий ≥ **0.15 мм**
- Высота символов ≥ **1.3 мм** (нечитаемое **удаляется**)
- На слоях топологии ≥ 1.7 мм

### Контур
- Допуск h12 ГОСТ 25347-82 (для плат ≥ 25×25 мм)
- Мин. радиус скругления 0.75 мм (фреза 1.5 мм); по умолчанию 1.25 мм (фреза 2.5 мм)
- Зазор медь–край: фрезеровка **0.30 мм** (кл. А) / **0.25 мм** (кл. В); скрайбирование
  **0.50 мм**; алюминий 0.70 мм

### Полигоны
- Векторные, ширина линии заливки ≥ 0.2 мм
- Минимальный элемент 0.3 мм (оптимум 0.4 мм внутри)

### Групповая заготовка
- Платы < 25×25 мм или < 625 мм² — только групповой заготовкой
- Расстояние между платами: **2.3 мм** при фрезеровке, встык при скрайбировании

### Прочее
- Коробление: 1.5 % (штыревой монтаж), 0.75 % (поверхностный)
- Изготовитель вправе менять ширину проводников и высоту диэлектрика **на ±25 %**
  без согласования — критичные по импедансу цепи оговаривать отдельно
- Электроконтроль обязателен для МСП и плат повышенной сложности; платы < 0.5 мм — только AOI
