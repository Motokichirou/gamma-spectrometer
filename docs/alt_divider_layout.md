## Посадка U402 — рассчитана, готова к записи

SOIC-8 с EPAD, пады локально: x = ±2.826, y = −1.905 / −0.635 / +0.635 / +1.905,
размер пада 1.66 × 0.56; EPAD 2.29 × 2.29 в (0,0). Габарит 8.48 × 7.54.

Радиально корпус **не влезает** (кольцо 15.9…22.0 = 6.1 мм при длине корпуса 7.3 мм),
поэтому ставим **тангенциально**, локальный +Y наружу ⇒ `поворот = φ − 90°`, и сдвигаем по дуге
так, чтобы вывод 2 (−IN) встал ровно на радиус анода.

```
радиус центра  = 15.9 + 0.2 (зазор) + 0.28 (полпада) + 1.905 (ряд) = 18.285
φ центра       = 329.9°        поворот = 239.9°
центр U402     = (325.819, 90.830)
вывод 2 (−IN)  = (326.687, 93.593)  R=17.87, угол 339.0° — тот же радиус, что анод
```

**Анодный проводник: 2.87 мм центр-центр / 1.69 мм край-край** (было 10.2 мм).
Контроль: пин5 ближе всех к краю платы — 2.11 мм; пин1 (FB) на R=16.62.

⚠ При записи проверить, что пады пинов 1–4 не наезжают на пады ФЭУ (расчётный зазор 0.2 мм)
и что EPAD не конфликтует со стойкой на R=19 / 30° — она в стороне, но померить.
