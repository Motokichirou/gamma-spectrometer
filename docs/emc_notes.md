# ЭМС: разбор рисков (2026-09-29)

Прогон скилла `emc` по `pcb/gamma_spectrometer/gamma_spectrometer.kicad_pcb`
(CISPR 32 Class B): балл **46/100**, 70 находок. Ниже — разбор, что из этого
относится к делу.

## Главное: частота преобразователя лежит в полосе шейпера

| | |
|---|---|
| CR-звено, τ = 1 мкс (R309 10к + C315 100п) | ФВЧ **159 кГц** |
| RC-звено, τ = 510 нс (R308 1к + C316 510п) | ФНЧ **312 кГц** |
| **полоса шейпера** | **159…312 кГц** |
| MAX1847, R202 = 180 кОм | **f = 252 кГц** |

252 кГц попадает **ровно в середину** полосы пропускания. Всё, что просочится
от преобразователя в тракт — ёмкостной или магнитной связью, по земле, по питанию —
не отфильтруется, а придёт на АЦП с максимальным коэффициентом передачи.

Через `−HV_out` этот путь закрыт: после трёх RC пульсации единицы нановольт
(`simulation/hv_loop/`). Открытые пути — излучение с T201 и умножителя на вход TIA,
и общая земля стека.

**Рычаг, если помешает:** сдвинуть частоту резистором `R202`. Вверх выгоднее, чем вниз:
за ФНЧ спад 12 дБ/окт (два полюса), за ФВЧ — 6 дБ/окт. При f ≈ 500 кГц получим ~8–10 дБ
подавления вместо нуля. ⚠ Смена частоты меняет рабочую точку трансформатора и петлю —
потребуется перепрогон `simulation/hv_loop/`.

**Проверять так:** снять спектр шума АЦП при выключенном и включённом ВВ. Линия на
252 кГц и её гармониках в разности — прямое подтверждение. Смотреть и на σ базовой линии
(расчёт: 0.31 канала), и на ложные срабатывания порога.

## Что скилл нашёл справедливо

| правило | где | что делать |
|---|---|---|
| **RP-001** error | `D_N` (USB D−): два перехода слоёв без сшивающего виа ближе 3 мм | самый неприятный пункт: это пара, уходящая в кабель, то есть и антенна, и приёмник. Добавить землю рядом с переходами |
| **ES-002** | у `U_ESD101` один земляной виа | второй виа вдвое снижает индуктивность пути ESD (~0.5 → 0.25 нГн) |
| **RP-001** warning | `HV_ENABLE`, `Net-(F101-Pad1)` (входная шина питания) | сшить переходы |
| **IO-002** | `J_PMT401`: 11 сигналов, 0 земляных выводов | по делу, но выводы задаёт ФЭУ. Экранирование — задача корпуса и μ-металла вокруг колбы |
| **SU-001**, **EE-001** | 2 слоя без опорного слоя; резонансы полости 377 / 754 / 1131 МГц | принять: переход на 2 слоя сделан осознанно под ЛУТ-прототипы |

## Что ложное для нашей конструкции

- **GP-001 ×22** — «разрыв опорной земли» под цепями `DY1…DY8`, `−HV_out`, `C210…C217`,
  `R221`. Земля там убрана **намеренно**, правилами 3 мм/кВ из `gamma_spectrometer.kicad_dru`.
  Залить их землёй = пробой. Анализатор про высокое напряжение не знает.
- **BE-001 ×11** — «дорожка у края платы». Скилл считает заготовку **прямоугольником
  188×45**, а у нас четыре круга Ø45. Проверил реальные расстояния до контура:

  | цепь | скилл | на самом деле |
  |---|---|---|
  | `Net-(U104-OUT)` | 0.19 мм | **+10.08 мм** |
  | `HV_CONTROL` | 0.48 мм | **+2.38 мм** |
  | `Net-(U103-3V3OUT)` | 0.74 мм | **+9.87 мм** |
  | `−5V_A` | 0.92 мм | **+2.38 мм** |

  Минимум по всей плате — 2.219 мм для дорожек и 0.501 мм для зон. Проблемы нет.
- **IO-001/IO-002 на `PANEL1`** — это футпринт отверстий разлома, а не разъём.
- **GP-004**, заполнение земли 41–55 % — для круглой платы Ø45 с ВВ-вырезами нормально.

## Формальная совместимость

Для единичного прибора «для себя» сертификация не нужна — ТР ТС 020/2011 распространяется
на продукцию в обращении. Если когда-нибудь понадобится, слабые места известны заранее:
**USB-кабель как основная антенна** (питание и связь идут по нему, синфазный ток с платы
ВВ выйдет именно туда) и **flyback 252 кГц с гармониками до десятков МГц**. Лечится
синфазным дросселем на USB и экраном на стек — ни того, ни другого сейчас нет.

## Что померить, когда соберём

1. **Ближнепольный пробник**: T201, умножитель (C210–C217), кварц Y301. Карта горячих точек.
2. **Спектр шума АЦП**: ВВ выключено → включено. Смотреть 252 кГц и гармоники.
3. **σ базовой линии** против расчётных 0.31 канала — интегральный показатель, что связь
   не испортила тракт.
4. **Положение пика Cs-137** при включённом и выключенном ВВ — если едет, есть связь
   по питанию или земле.
5. **Ток по оплётке USB** токовыми клещами — оценка синфазной составляющей.
