## Плата МК (v1.6 → следующая)

- [ ] **100 нФ на NRST → GND.** Без него МК сам сбрасывался; сейчас 100 нФ припаян навесом.
  — `docs/mcu_board_bringup.md` §3.2, §5 п. 1
- [ ] **Пад 0402 на BOOT0 (PB8, вывод 45)** — резистор вверх/вниз (или кнопка/пятак). Сейчас провод
  с ножки 45 → 10 кОм (+3.3 В — загрузчик, GND — прошивка). ⛔ PB8 не GPIO, светодиод не вешать.
  — `docs/mcu_board_bringup.md` §3.4, §5 п. 2
- [ ] **Пятаки SWD** (SWDIO, SWCLK, NRST, GND, 3.3 В) у выводов LQFP-48 **37 / 38 / 7**. SWD на v1 так
  и не заработал, прошивка только через загрузчик по UART (`!boot` + прошивальщик `gammapult`).
  — `docs/mcu_board_bringup.md` §3.3, §5 п. 3
- [ ] **Пад GND для Pt1000 у `TP_TSENS301`** (сейчас там только TSENS_PWR + TSENS_IN); R303.2 соединить
  с PB12. На v1 — перемычка между падами, Pt1000 на GND.
  — `docs/mcu_board_bringup.md` §5 п. 5, §6.3
- [ ] **Дорожка SYNC: MAX1847 U201 вывод 16 (сейчас GND) → новый пин шины стека → свободный вывод МК
  с таймером**, f_SYNC ≈ 270 кГц (f_osc ≈ 0.95·f_SYNC при R202 = 180 к), АЦП брать синхронно с
  преобразователем. Причина: остаток помехи 257 кГц ~1.3 LSB сидит в опоре/земле АЦП (виден на VREFINT),
  экраном не лечится. Требования SYNC по даташиту: ≥2.0 В, 100–500 кГц, фронты ≤200 нс, импульс ≥200 нс.
  — `docs/hv_board_bringup.md` §1a (около стр. 134)
- [ ] **Подтяжки/земля на висящих выводах интерфейсов загрузчика** PB13–15, PA11/12 — продумать.
  — `docs/mcu_board_bringup.md` §5 п. 4
- [ ] **Сплошная земля под шейпером на стороне, обращённой к плате ВВ; узлы шейпера — подальше от
  проекции умножителя.** Основной путь помехи — ёмкостный, от умножителя к шейперу.
  — `docs/hv_board_bringup.md` §1a
  Попутно по модели земли (`simulation/ground_mcu/`, 2026-11-14): сплошной B.Cu под шейпером
  (x 181.8…198.2, y 84.5…115.8) снижает наводку от цифры и флеша по земле ~в 3 раза (17 → 6 и 39 → 13 мкВ).
  Дёшево, но на спектр не влияет (уже ≤ 0.1 LSB).
- [ ] **Прямая земля МК ↔ USB-плата в обход платы ВВ** (пины шины). Сейчас МК связана с опорами питания
  только через плату ВВ, где текут импульсные токи ключа; модель меди платы МК даёт 0.04 LSB против
  измеренных ~1.3 LSB — остаток в разности VREF+ − VSSA / питании через плату ВВ.
  — `simulation/ground_mcu/README.md`, `docs/hv_board_bringup.md` §1a

## Возможно — проверить на приборе

- [ ] **R308 1 кОм → 2 кОм?** При 3.5 МэВ ток через R308 ≈ 2 мА против 500 мкА нагрузки ОУ по DS12288
  (стр. 164); с 2 кОм — 0.49 мА. Шейпер V2 оставил 1 кОм — **проверить на приборе** (амплитуда/линейность
  у верха шкалы) прежде чем менять.
  — `firmware/board_g474cb/SPEC.md` §10 (2026-11-06, около стр. 566)

## Процесс (напоминания)

- [ ] После любого «Обновить плату из схемы» или сноса разводки — **сверить число отверстий по каждому
  сверлу и по каждой плате** (механические футпринты без символов — стойки, цанг-пины, коаксиал,
  `H_HV301`, `TP_TSENS301` — пропадают молча). — `CLAUDE.md` «Что осталось» п. 2
- [ ] **НЕ запускать `pcb/panelize.py`** — на собранной заготовке сдвинет платы повторно.
  — `docs/mcu_lqfp48_migration.md` п. 12 (стр. 132)
- [ ] **DRC с ВВ-правилами** (`pcb/gamma_spectrometer/gamma_spectrometer.kicad_dru`, 49 правил) после всех
  правок; «не соединено» — только межплатные. — `CLAUDE.md` «Что осталось» п. 2
