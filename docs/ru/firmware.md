# Прошивка

<!-- README-I18N:START -->
**Русский** | [English](../en/firmware.md)
<!-- README-I18N:END -->

Боевая прошивка платы МК — [`firmware/gamma_fw/`](../../firmware/gamma_fw/). Написана с нуля по ТЗ
[`firmware/board_g474cb/SPEC.md`](../../firmware/board_g474cb/SPEC.md): голые регистры CMSIS, без HAL.
Переносимая логика лежит в `src/core/` и покрыта тестами на ПК, драйверы железа — в `src/hw/`.
Совместима с [BecqMoni](https://github.com/Am6er/BecqMoni) / AtomSpectra по протоколу shproto
(см. [protocol.md](protocol.md)).

## Тракт и тактирование

| Параметр | Значение |
|---|---|
| МК | STM32G474CBT6, 156 МГц от кварца 16 МГц (PLL M=2, N=39, R=2) |
| Сигнальный АЦП | ADC3_IN1 (PB1), 12 бит, **3.467 Мвыб/с**, выборка 2.5 такта, непрерывно по DMA порциями по 8192 отсчёта |
| Шейпер | встроенные OPAMP1 и OPAMP2 — интеграторы (τ ≈ 1 и ≈ 1.8 мкс), OPAMP3 — PGA ×4 |
| База АЦП | ≈0.394 В (≈645 кодов); импульсы положительные: `amplitude = sample − baseline` |
| Импульс | фронт 10 %→пик 5–6 отсчётов, FWHM ≈14 отсчётов (3.6 мкс) |
| Спектр | 8192 канала, канал = 2 × амплитуда в кодах АЦП |
| Служебные АЦП | монитор ВВ (ADC2), VREFINT (опора), Pt1000 через OPAMP6 ×8 (ADC4), +3.3V_D |

## Модули

| Модуль | Что делает |
|---|---|
| `core/detector.c` | Поиск импульсов, отбраковка наложений и выбросов, амплитуда по эталону формы, слежение за базой, авто-порог 5σ |
| `core/acq.c` | Набор: старт/стоп/сброс, живое и реальное время, загрузка ЦП |
| `core/spectrum.c` | Гистограмма 8192 канала |
| `core/proto.c`, `core/shproto.c` | Протокол shproto: кадры спектра и статуса, текстовые команды |
| `core/svc.c` | Служебные замеры и сервисные команды (`-hv`, `-gst`, `-diag` …) |
| `core/hv_ctl.c` | Управление ВВ: плавный подъём, подстройка по монитору, аварии |
| `core/temp.c` | Температура Pt1000 |
| `core/settings.c`, `core/flashstore.c`, `core/becq_cal.c` | Настройки, эталон и калибровка BecqMoni во флеш |
| `core/dactest.c` | Самотест тракта импульсами встроенного ЦАП |
| `core/tpl_pmt.h` | Эталон формы импульса, снятый с реального тракта (64 фазы × 7 отсчётов, Q14) |
| `core/tpl_dac.h` | Эталон формы импульса ЦАП для самотеста |
| `hw/*` | Тактирование, АЦП, ОУ, ШИМ ВВ, UART, флеш, переход в загрузчик |

## Детектор

- Импульс ловится по порогу над базой. Порог задаётся в кодах АЦП или выбирается автоматически
  (5σ шума базы).
- Амплитуда считается подгонкой эталона формы по 7 отсчётам вокруг максимума с перебором 64
  суб-отсчётных фаз. Эталон снимается с реального тракта (`tools/tpl_pmt.py`) и вшит умолчанием.
  Свой эталон можно загрузить командами `-tplw`/`-tplok` и сохранить во флеш `-save`.
- Отбраковка: ширина вне окна (на плате 4…56 отсчётов), наложения, плохая форма (χ²), выбросы помехи.
- База отслеживается по спокойным отсчётам. После импульса 40 отсчётов в базу не идут: хвост
  длинного импульса.

## Высокое напряжение

- Уставка 0…1200 В командой `-hv`. Подъём плавный, выход подстраивается по монитору ВВ.
- Защиты: потолок умножителя 1300 В, отказ опоры, застрявший монитор, отклонение выхода. ВВ
  выключается при переходе в загрузчик.
- Рабочая точка зависит от ФЭУ. На текущем детекторе ~735–755 В, пик Cs-137 на канале ~1160–1200.

## Команды

Команды BecqMoni: `-sta`, `-sto`, `-rst`, `-stt`, `-sho`, `-mode`, `-inf`, `-cal` (энергокалибровка
в формате BecqMoni, 40 регистров).

Сервисные команды (ответ одной строкой `-ok …` / `-err …`):

| Команда | Что делает |
|---|---|
| `-hv <0…1200>` / `-hv off` / `-hv` | Уставка ВВ, В / выключить / запрос |
| `-hvzero`, `-hvk [мВ/В]` | Калибровка монитора ВВ: ноль и коэффициент |
| `-ptcal <°C>` | Калибровка Pt1000 по эталонной температуре |
| `-gst` | Состояние прибора одной строкой `key=value`: ВВ, опора, температура, база, шум, загрузка, живое время |
| `-diag` | Напряжения узлов тракта и вердикт по нормам |
| `-thr [коды]` | Порог детектора в кодах АЦП (0 — авто 5σ) |
| `-opa [hs 0\|1 \| pga 2\|4\|8\|16]` | Режим ОУ шейпера и усиление PGA (только вне набора, во флеш не пишется) |
| `-smp`, `-noise` | Время выборки АЦП; замер шума базы |
| `-osc [raw]` | Окна импульсов или сырые порции АЦП (кадры 0x02) |
| `-dac …` | Тестовые импульсы встроенного ЦАП |
| `-tplw`, `-tplok`, `-tplclr` | Загрузка эталона формы (64 строки) / применить / вернуть вшитый |
| `-tc [t0 k1 k2]` | Коэффициенты термокомпенсации усиления (запрос без аргументов) |
| `-save`, `-defaults` | Записать настройки во флеш / вернуть умолчания (в ОЗУ) |
| `!boot` | Выключить ВВ и перейти в системный загрузчик (обновление прошивки) |

## Сборка, тесты, обновление

- Сборка: `sh firmware/gamma_fw/build.sh` (arm-none-eabi-gcc), проверяется бюджет ОЗУ.
- Тесты на ПК: `firmware\gamma_fw\tests\run_tests.cmd`.
- Обновление по USB, без программатора:
  `python -I firmware/gamma_fw/tools/gfw.py flash firmware/gamma_fw/gamma_fw.bin`.
  Прошивка получает `!boot`, выключает ВВ и уходит в системный загрузчик STM32 (USART1 через FT231X).
  SWD на первом экземпляре платы не работает. Если основная прошивка не стартует, в загрузчик можно
  попасть через вывод BOOT0.
- Инструменты (`firmware/gamma_fw/tools/`): `gfw.py` (команды, спектр, прошивка), `tpl_pmt.py`
  (эталон формы с реального тракта), `tpl_dac.py` (эталон ЦАП).

## Известные ограничения

- Под высокой загрузкой (≥5 кимп/с) база проседает, и разрешение немного падает.
- Обрыв и замыкание Pt1000 пока не диагностируются.
- Живое время не учитывает отбракованные импульсы.
- Самотест ЦАП ещё не пересчитан под длинный импульс текущего шейпера.

Подробности, замеры и журнал находок — в [SPEC.md](../../firmware/board_g474cb/SPEC.md).
