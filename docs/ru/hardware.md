# Обзор аппаратной части

<!-- README-I18N:START -->
**Русский** | [English](../en/hardware.md)
<!-- README-I18N:END -->

Прибор — цилиндрический стек из четырёх плат Ø45 мм, установленных прямо за
сцинтиллятором NaI(Tl) Ø63×63 мм, сопряжённым с ФЭУ Hamamatsu R1307. Единственный
кабель USB-C выходит с торца и несёт и питание, и данные.

## Стек плат (снизу → вверх)

```
[торец — кабель USB-C]
  1. USB/Power board   Ø45 мм   USB-C (JAE DX07S024WJ3R400)
  2. HV board          Ø45 мм   MAX1847 flyback + 4-ступ. CW умножитель, 0…−1500 В
  3. MCU board         Ø45 мм   STM32G474CBT6, шейпер CR-RC², АЦП
  4. Divider board     Ø42–45 мм  делитель R1307 + ADA4817 TIA
[торец — ФЭУ R1307 + NaI(Tl)]
```

### Межплатные соединения

Разъёмов в стеке нет — всё паяется.

| Связь | Откуда → Куда | Как |
|---|---|---|
| Шина стека (питание, управление, ±5V_A делителя) | плата ↔ плата | цанговые пины Ø1.5 мм на дуге R20 мм, соосные; 44 посадочных места: USB 11, ВВ 15, МК 13, делитель 5 |
| Сигнал `AMP_OUT` | делитель → МК | тонкий коаксиал, припаянный к парам пятаков (сигнал + оплётка) |
| −ВВ | ВВ → делитель | экранированный провод ≥5 кВ через отверстие Ø4.5 мм в плате МК |
| Pt1000 | корпус кристалла → МК | витая пара на пятаки |
| Механика | — | по три стойки M2.5 (земля) в центре каждой платы |

### Печатные платы

- 2 слоя, 1.5 мм; все четыре платы собраны в одну заготовку 187.5 × 45 мм с перемычками
  под разлом. Изготовитель — ПС-Электро. Шелкографии нет.
- Нормы ВВ-зазоров 3 мм/кВ заданы правилами в `pcb/gamma_spectrometer/gamma_spectrometer.kicad_dru`.

## Цепь сигнала

```
NaI(Tl)+R1307 → ADA4817 TIA (Zt=499Ω) → коакс → CR(OPAMP1) → RC(OPAMP2) → PGA×4(OPAMP3) → ADC
[плата делителя] ±5V_A                τ=1 мкс       τ=510 нс      DC=0.41 В       3.3 В
анод ≈ 0 В (вирт. земля)  amp_out = +469 мВ @Cs-137   [плата МК — G474]
```

**Полярность:** импульс на АЦП идёт *вверх* от baseline 0.41 В (анод ФЭУ забирает ток,
выход TIA растёт). В DSP: `amplitude = sample − baseline`.

## 1. Плата USB/питания

Интерфейс USB-C и все шины питания стека.

- **FT231XQ** (QFN-20) — мост USB ↔ UART на 600 кбит/с, виден как виртуальный COM-порт.
- **LP5907** → +3.3V_A (малошумящий аналог), **AMS1117CD-3.3** → +3.3V_D (цифра).
- Зарядовый насос **TPS60400** → −5V_A.
- LC-фильтры 47 мкГн на +5V_A и −5V_A (≈84 дБ @ 300 кГц).
- **+5V_HV** — сырой USB 5 В через LC-фильтр на плату ВВ.
- ESD-защита **PRTR5V0U2X** на линиях данных USB.
- Бюджет USB 2.0 ≈ 370 мА < 500 мА.

Детальная схема: [`docs/usb_power_board_schematic.md`](../usb_power_board_schematic.md).

## 2. Плата ВВ

Генерирует регулируемое отрицательное высокое напряжение для ФЭУ.

- Контроллер flyback **MAX1847** + ключ **IRLML0060** (60 В: запас над выбросом стока
  43–45 В в худшем случае) + трансформатор **ATB322524** (1:10.2).
- Снаббер первичной обмотки: BAS516 + 10 нФ (100 В) + 2×BZT52C18.
- **4-ступенчатый** умножитель Кокрофта–Уолтона (8 диодов BAV23S), 0 … −1500 В.
- Питается от сырой шины +5V_HV (не от чистых аналоговых шин).
- Выходной RC-фильтр (3×100 кОм + ВВ-конденсаторы): пульсации на выходе — единицы нВ.
- Обратная связь: выход CW → делитель 1 ГОм → усилитель ошибки MAX1847; `V_HV = −V_CTRL × 454.5`.
  Петля устойчива с запасом по фазе 90–100° во всём диапазоне 500–1500 В. Фильтр стоит вне петли,
  поэтому под нагрузкой выход ≈ 0.958 × уставки — компенсируется программно по `HV_MONITOR`.
- Мониторинг: делитель 68 МОм + опора **TL431** → `HV_MONITOR` на пин АЦП МК.
- `HV_ENABLE` активный HIGH (HIGH от МК = ВВ включено), подтяжка к земле держит ВВ
  выключенным, пока МК не запущен.
- Собранная плата заливается силиконом после проверки.

Детальная схема: [`docs/hv_board_schematic.md`](../hv_board_schematic.md).

## 3. Плата МК (v1.6)

Ядро обработки сигнала и интерфейса.

- **STM32G474CBT6** (LQFP-48, флеш 128 КБ) @ 170 МГц со встроенными **OPAMP1/2/3** и 12-бит
  АЦП на 4 Мвыб/с. До октября 2026 плата была под LQFP-80 — переразведена, когда заказ
  80-выводного чипа сорвался; все задействованные выводы есть и в 48-выводном корпусе.
- Вход: коаксиал с ~470 мВ @Cs-137 от ADA4817 TIA на плате делителя.
- Аналоговый шейпер: **CR** (10 кОм + 100 пФ + 10 кОм) → **RC** (1 кОм + 510 пФ + 1 кОм),
  формирует импульс типа CR-RC², далее PGA ×4 в АЦП.
- Опора напряжения **REF35250** (2.500 В, 12 ppm/°C, SOT-23-6) плюс делители DC-смещения
  для baseline АЦП. Без неё плата работает от внутреннего VREFBUF МК (2.500 В ±0.16 %).
- SPI-флеш **W25Q64**, кварц 16 МГц (CL 9 пФ).
- Датчик температуры **Pt1000** (тонкоплёночный, класс A, с выводами) на корпусе кристалла,
  читается ratiometric через ADC4 для термокомпенсации дрейфа.
- `HV_CONTROL` PWM → RC-фильтр → плата ВВ.
- Программирование — по SWD проводами прямо к выводам МК (37 SWDIO, 38 SWCLK, 7 NRST);
  дальнейшие обновления — через системный загрузчик по тому же USB-UART.

Детальный док: [`docs/adc_mcu_board.md`](../adc_mcu_board.md).

## 4. Плата делителя

Активный делитель ФЭУ и входной усилитель, ближе всего к трубке.

- **Hamamatsu R1307-01** (гибкие выводы), 11 пинов.
- Резистивная цепочка R401–R412, 7.72 МОм (тейпер под спектрометрию); накопительные капы
  только на последних динодах (C408/C409/C410 = 22/47/100 нФ на Dy6–Dy8).
- Три транзисторных буфера **MMBTA42** (Q401/Q402/Q403) на динодах Dy6/Dy7/Dy8, смещены
  током делителя (цепочка идёт через диноды эмиттерными резисторами, по Hamamatsu Fig 5-15).
  Защитные диоды B–E D401–D403 (1N4148W) — от обратного пробоя на рампе ВВ.
- **ADA4817-1ARDZ** трансимпедансный усилитель (TIA): анод напрямую на −IN (виртуальная
  земля), `Rf = 499 Ом`, `Cf = 4.7 пФ` (NP0), Zt = 499 Ом, полоса ≈ 92 МГц. На ~18% тише
  прежнего AD8000-инвертора. На выходе — 22 Ом (без него TIA возбуждается на реальной
  входной ёмкости 3.4–4.6 пФ, найдено моделированием паразитов).
- Питается от ±5V_A, поданных по стеку.

Детальный док: [`docs/divider_board.md`](../divider_board.md).
