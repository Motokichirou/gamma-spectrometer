# simulation/hv_loop — пульсации ВВ, устойчивость петли MAX1847, наводка на FB

Расчёт 2026-09-20. Итоги и выводы для схемы — `docs/hv_board_schematic.md` §12.

## Модель

`hv_deck.py` собирает нетлист LTspice по реальной схеме платы ВВ (сверено с `pcb/gamma_spectrometer.net`):
MAX1847 поведенчески (gm 400 мкА/В, Ro 3 МОм, A_CS 3.3, компенсация наклона 41 мВ/мкс, предел тока
100 мВ, ШИМ-защёлка на `DFLOP`), T201 с индуктивностью рассеяния, снаббер, умножитель **на 4 ступени**,
RC-фильтры, нагрузка делителем ФЭУ, делитель обратной связи 1 ГОм / 2.2 МОм.

Допущения (в даташите их нет): смещение ШИМ-компаратора 1 В (на малый сигнал не влияет), бланкирование
100 нс, зажим COMP 0.5…3.5 В, **полоса усилителя ошибки не ограничена** ⇒ оценка наводки сверху.
Lp = 5.6 мкГн (по кривой L(I) при рабочем токе), C13–C17 взяты с запасом −30 % (X7R под высоким DC).

Установление из начальных условий: заряжать 0.25 мкФ до 1500 В — около секунды модельного времени,
поэтому напряжения на всех конденсаторах задаются через `IC=`.

## Скрипты

| файл | что делает |
|---|---|
| `hv_deck.py` | генератор нетлиста; `fbnet=eps` вставляет реальную цепочку FB и матрицу ёмкостей |
| `spice_io.py` | запуск LTspice (пониженный приоритет, CPU0 свободен) и разбор `.raw`/`.log` |
| `run_base.py` | установление при 1200 и 1500 В, баланс мощности, ток стабилитронов |
| `run_ripple.py` | пульсации: ток умножителя из модели → линейная сеть фильтров |
| `run_fra.py`, `run_rest.py`, `run_500small.py` | петлевое усиление: синус в разрыв FB, синхронное детектирование |
| `loop_model.py` | усреднённая аналитическая модель петли (сверка с замером) |
| `run_pickup.py` | чувствительность к наводке: сосредоточенная Cs 1…100 фФ на FB |
| `extract_hv.py` | геометрия меди платы ВВ из `.kicad_pcb` (интерпретатор KiCad, только чтение) |
| `fastcap_hv.py` | матрица паразитных ёмкостей (FastCap2) |
| `fb_pickup_net.py` | наводка на FB по матрице и реальной форме A-колонки (по гармоникам) |
| `run_fbnet.py`, `run_fbnet_v.py` | сквозная проверка: сеть внутри модели + варианты лечения |

Порядок: `extract_hv.py` (KiCad Python) → `fastcap_hv.py` → `run_fbnet.py`.

## Итоги

- Пульсации на −HV_out после 3×RC — единицы нановольт; на CW_out 22–45 мВ пп. Реальный уровень задаст
  разводка, а не схема.
- Петля устойчива: срез 1.3–2.7 кГц, запас по фазе 90–100° при 500…1500 В, усиление на НЧ 80 дБ.
- RC-фильтр 3×100 кОм стоит **вне** петли (FB снимается с CW_out) ⇒ −HV_out = уставка × 0.958.
- 🔴 Наводка с умножителя на FB: 1.4 фФ по FastCap → 123–150 мВ пп на FB → без C_COMP2 петля упирается
  в потолок и ВВ проседает на 9 В. **Нужен C219 = 15…22 пФ с COMP на GND.**

## Грабли

- Инжекция для замера петли должна быть мала относительно рабочей точки COMP: при 500 В амплитуда
  100 мкВ модулировала COMP на 30 % и дала ложные «50° запаса» (на деле 100°).
- Низкие частоты дороги: точка 50 Гц — это 90 мс модельного времени, часы счёта. Начинать с окрестности среза.
- Прогоны с сетью FB при 500 и 1500 В зависают (жёсткая смесь 100 МОм и фемтофарад в хаотичном режиме):
  гонять с `tsave=0`, коротким `tstop`, мягким `reltol`.
- Средние по `.raw` считать с весом по времени: шаг LTspice переменный и сгущается на фронтах.
- Землю FastCap отдаёт отдельным проводником: её взаимную ёмкость нельзя вычитать из ёмкости узла.
- `out/` весит десятки гигабайт (`.raw`), в git не идёт — чистить после разбора.
