# gammapult — сервисное ПО на ПК (диагностика и калибровка)

Нативное Windows-приложение (C++ / Win32 / DirectX 11 / Dear ImGui + ImPlot).
Собирается в **единый исполняемый файл без внешних зависимостей** (статический CRT —
не нужны ни Python, ни Java, ни рантаймы).

Роль: сервисный компаньон к [BecqMoni](https://github.com/Am6er/BecqMoni) — связь,
диагностика, живой спектр, мастер энергокалибровки и конфигурация прибора. Повседневный
просмотр и сбор спектров можно вести в BecqMoni; калибровка `gammapult` совместима с его
кнопками «Записать/Читать с устройства» (см. [протокол](../docs/ru/protocol.md)).

> **Статус (2026-11-07):** работает с боевой прошивкой `firmware/gamma_fw` — телеметрия `-gst`, управление ВВ
> и подстройка по пику, калибровки монитора ВВ и Pt1000, порог и PGA, самотест линейности по ЦАП, сохранение
> во флеш, мастер обучения эталона формы, мастер термокомпенсации. Энергокалибровка — в BecqMoni
> (кнопка «Записать в устройство»).

> Сервисный тул свободен: он не обязан быть совместим с чужими форматами. Протокол
> shproto он не меняет — пользуется собственными командами уровня приложения.

## Двойной режим: один инструмент, два файла

Сборка даёт два файла с общим именем:

| Файл | Подсистема | Когда запускается |
|---|---|---|
| `gammapult.exe` | GUI (Windows) | двойной клик / без аргументов → графический интерфейс |
| `gammapult.com` | консоль | из терминала с подкомандой → CLI для автоматизации |

В консоли Windows при вводе `gammapult …` приоритет имеет `.com` (правило PATHEXT),
поэтому `gammapult info --port COM6` уходит в CLI, а двойной клик по `.exe` открывает окно.

## GUI (`gammapult.exe`)

Раскладка из раздвижных панелей:

- **Подключение** — COM-порт (по умолчанию последний в списке — обычно мост FT231X), старт/стоп/сброс
  набора, серийник и версия прошивки. При подключении набор не трогается (`-stt`).
- **Телеметрия** — опрос `-gst` раз в секунду: ВВ (уставка/выход/авария), температура и состояние Pt1000,
  база и шум, импульсы на входе/принятые/брак, порог, живое время, загрузка ЦП, опора, флеш.
- **Высокое напряжение** — уставка с подтверждением включения, красная кнопка «Выключить ВВ»; мастер
  **подстройки ВВ по пику**: набор → центроид пика в окне → новое ВВ по закону усиления V^k (шаг ≤ 15 %),
  пока пик не встанет на заданный канал с точностью 1 %.
- **Спектр** — живой график (ImPlot): Лин/Лог, колесо = масштаб X, Shift+колесо = Y; грубая оценка пика и
  FWHM; при подстройке ВВ — окно и цель.
- **Консоль** — лог обмена (опрос `-gst` в лог не пишется), чипы быстрых команд, произвольная команда.
- **Сервис** — вкладки:
  - *Самотест ЦАП* — серия импульсов ЦАП по ступенькам 1…1350 кодов, центроиды, прямая, R², отклонение;
  - *Калибровки* — ноль монитора ВВ (`-hvzero`), коэффициент по мультиметру (`-hvk`), Pt1000 по эталону (`-ptcal`);
  - *Эталон* — сбор сырых порций (`-osc raw`, ≈2000 за ~11 мин при ВВ и источнике), расчёт эталона формы
    (алгоритм `tools/tpl_pmt.py`, результат совпадает бит в бит), загрузка `-tplw ×64` + `-tplok`, `-save`;
  - *Термо* — запись пика источника против температуры Pt1000 (поправка на время записи выключена),
    расчёт k1/k2 и запись `-tc t0 k1 k2` + `-save`;
  - *Настройки* — порог в кодах АЦП (`-thr`, 0 — авто 5σ), PGA (`-opa`), `-save`, `-diag`, `-noise`, `-defaults`.
- **Справка** — встроенная инструкция.

## CLI (`gammapult.com`) — для автоматизации

```
gammapult list                                   # перечислить COM-порты
gammapult info    --port COM4                    # прошивка, серийник, порог
gammapult gst     --port COM4                    # телеметрия key=value
gammapult acquire --port COM4 --seconds N [--out file.csv]   # набор спектра
gammapult lin     --port COM4 [--codes "100 600 1300"] [--n 10000] [--period 100]   # самотест ЦАП
gammapult cmd     --port COM4 --send "-diag" [--read СЕК]   # произвольная команда
gammapult tpl collect --port COM4 [--n 2000] --out raw.bin    # сырые порции (uint16 × 8192 подряд)
gammapult tpl build raw.bin [--out tpl.h] [--load --port COM4 [--save]]   # эталон из порций
```

`acquire --out` пишет CSV `channel,count`. `lin` печатает центроиды ступенек и прямую (как `gfw.py lin`).

## Сборка

Нужен **Visual Studio Build Tools 2022** (воркфлоу «Desktop C++»: MSVC, Windows SDK,
C++ CMake tools). Из корня репозитория:

```powershell
$cmake = "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe"
& $cmake -G "Visual Studio 17 2022" -A x64 -S host -B host/build   # configure (1 раз)
& $cmake --build host/build --config Release
```

Зависимости (Dear ImGui v1.90.9, ImPlot v0.16) подтягиваются автоматически через CMake
FetchContent (на этапе configure нужен интернет). Результат:
`host/build/Release/gammapult.exe` и `gammapult.com`.

## Структура

```
host/
├── CMakeLists.txt      # цели gammapult (GUI) и gammapult_com (CLI, SUFFIX .com)
└── src/
    ├── entry.cpp       # диспетчер режимов GUI/CLI
    ├── main.cpp        # окно Win32 + DX11 + цикл ImGui/ImPlot (GUI)
    ├── cli.cpp         # подкоманды CLI поверх класса Device
    ├── device.*        # сессия с прибором: -gst, очередь команд, самотест ЦАП, подстройка ВВ, сбор порций, термо
    ├── tpl_learn.*     # расчёт эталона формы по сырым порциям (порт tools/tpl_pmt.py)
    ├── serial_win.*    # COM-порт через Win32 API
    ├── shproto.*       # кадры shproto (BecqMoni / AtomSpectra)
    └── theme.*         # тема и шрифты ImGui (латиница/греческий/кириллица)
```
