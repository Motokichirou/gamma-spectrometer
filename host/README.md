# gammapult — сервисное ПО на ПК (диагностика и калибровка)

Нативное Windows-приложение (C++ / Win32 / DirectX 11 / Dear ImGui + ImPlot).
Собирается в **единый исполняемый файл без внешних зависимостей** (статический CRT —
не нужны ни Python, ни Java, ни рантаймы).

Роль: сервисный компаньон к [BecqMoni](https://github.com/Am6er/BecqMoni) — связь,
диагностика, живой спектр, мастер энергокалибровки и конфигурация прибора. Повседневный
просмотр и сбор спектров можно вести в BecqMoni; калибровка `gammapult` совместима с его
кнопками «Записать/Читать с устройства» (см. [протокол](../docs/ru/protocol.md)).

> **Статус (2026-11-14):** релиз **v0.7.0** (новый интерфейс: главный экран, мастер настройки, расширенный режим).
> Работает с боевой прошивкой `firmware/gamma_fw` — телеметрия `-gst`, управление ВВ и подстройка по пику,
> калибровки монитора ВВ и Pt1000, порог и PGA, самотест линейности по ЦАП, сохранение во флеш, обучение эталона
> формы и таблицы хвоста, поправка DNL АЦП (только CLI), термокомпенсация, регистратор. Энергокалибровка точнее —
> в BecqMoni (кнопка «Записать в устройство»).

> Сервисный тул свободен: он не обязан быть совместим с чужими форматами. Протокол
> shproto он не меняет — пользуется собственными командами уровня приложения.

## Ввод в строй с нуля

**Мастер настройки** (кнопка «Начать/Продолжить настройку» на главном экране или «Мастер» в верхней полосе) ведёт
от собранного железа (стек + делитель + ФЭУ + кристалл) до прибора, готового к работе в BecqMoni. Девять шагов:

1. **Прошивка** встроенным образом `gamma_fw` через системный загрузчик STM32 — свой протокол (AN3155), без
   STM32CubeProgrammer. Голый МК: BOOT0 (вывод 45) через 10 кОм на +3.3 В и переподключить USB; прибор с прошивкой
   уходит в загрузчик сам по `!boot` (ВВ при этом выключается). Пустой МК / смена DBANK — полное стирание, иначе
   стираются только страницы под образ (настройки и энергокалибровка в последней странице сохраняются).
   DBANK=1 исправляется на 0 записью опций. После прошивки BOOT0 вернуть на GND;
2. **Проверка электроники** без ВВ: `-diag`, опора, шум базы, Pt1000 (калибровка по эталону — по желанию),
   самотест линейности ЦАП;
3. **Ноль монитора ВВ**;
4. **Подбор ВВ** по пику Cs-137 (источник вплотную к торцу детектора);
5. **Форма импульса** — обучение эталона и таблицы хвоста для разбора наложений (пишутся в прибор вместе);
6. **Подбор ВВ ещё раз** (с новой формой пик слегка сдвигается);
7. **Разрешение**: набор и подгонка фотопика гауссом;
8. **Шкала энергий** по Cs-137 (E = k·канал, формат BecqMoni) — точнее по нескольким линиям в BecqMoni;
9. **Сохранение и отчёт**: `-save`, выбор автозапуска ВВ (`-hvboot`) и отчёт
   `gammapult_ввод_<серийник>_<дата>.txt` в папке пульта.

Термокомпенсация — отдельно, на странице «Термокомпенсация» расширенного режима (нужен прогрев/остывание на 5–10 °C).

## Двойной режим: один инструмент, два файла

Сборка даёт два файла с общим именем:

| Файл | Подсистема | Когда запускается |
|---|---|---|
| `gammapult.exe` | GUI (Windows) | двойной клик / без аргументов → графический интерфейс |
| `gammapult.com` | консоль | из терминала с подкомандой → CLI для автоматизации |

В консоли Windows при вводе `gammapult …` приоритет имеет `.com` (правило PATHEXT),
поэтому `gammapult info --port COM6` уходит в CLI, а двойной клик по `.exe` открывает окно.

## GUI (`gammapult.exe`)

Три режима; верхняя полоса показывает прибор, состояние ВВ, красную кнопку «Выключить ВВ», «Сохранить» (`-save`),
переключатели «Мастер» / «Расширенный», кнопку «Главная» (путь назад из мастера и расширенного режима) и «Отключить».
Справа в строке состояния — справка, язык (русский/English) и масштаб интерфейса.

- **Главный экран** — «Прибор не настроен» (прогресс по шагам мастера, «Начать настройку») либо «Всё готово, можно
  мерить» (состояние: ВВ, температура кристалла, счёт, опора, регистратор, разрешение, шкала; кнопка «Отдать порт
  BecqMoni»; задачи: самотест, регистратор, обновление прошивки, шкала, повторная настройка, термокомпенсация).
- **Мастер настройки** — девять шагов (см. выше), рейка шагов слева.
- **Расширенный режим** — слева навигация по страницам, посередине страница, справа колонка телеметрии и журнал обмена:
  - *Прибор:* Обзор (подключение, старт/стоп/сброс набора, серийник, версия; при подключении набор не трогается `-stt`),
    Спектр (живой график ImPlot: Лин/Лог, колесо = масштаб X, Shift+колесо = Y; грубая оценка пика и FWHM),
    Высокое напряжение (уставка с подтверждением включения, подстройка по пику: набор → центроид в окне → новое ВВ
    по закону усиления V^k, шаг ≤ 15 %, пока пик не встанет на канал с точностью 1 %; автозапуск `-hvboot`);
  - *Настройка:* Форма импульса (сбор сырых порций `-osc raw`, расчёт эталона — алгоритм
    `firmware/gamma_fw/tools/tpl_pmt.py`, результат совпадает бит в бит; загрузка `-tplw ×64` + `-tplok`, следом таблица
    хвоста `-tlw ×64` + `-tlm ×4` + `-tlok`, `-save`), Шкала энергий, Термокомпенсация (запись пика источника против
    температуры Pt1000, расчёт k1/k2, запись `-tc t0 k1 k2` + `-save`), Порог и детектор (порог в кодах АЦП `-thr`,
    0 — авто 5σ; PGA `-opa`; `-save`, `-defaults`), Датчики (ноль монитора ВВ `-hvzero`, коэффициент по мультиметру
    `-hvk`, Pt1000 по эталону `-ptcal`);
  - *Обслуживание:* Самотест (`-diag`, `-noise`, самотест ЦАП: импульсы по ступенькам 1…1350 кодов, центроиды, прямая,
    R², отклонение), Регистратор (автономные записи во флешку: автозапуск, сессия вручную, синхронизация времени,
    выгрузка журнала в папку, график пика и температуры, «В термокомпенсацию», «Сложить с выравниванием», стирание),
    Прошивка, Консоль команд (лог обмена, быстрые команды, произвольная команда; опрос `-gst` в лог не пишется).
- **Справка** — встроенная инструкция (кнопка в строке состояния).

Поправка DNL АЦП (`-dnl`) есть только в CLI (`adc dnl`).

## CLI (`gammapult.com`) — для автоматизации

```
gammapult list                                   # перечислить COM-порты
gammapult info    --port COM4                    # прошивка, серийник, порог (коды АЦП)
gammapult gst     --port COM4                    # телеметрия key=value
gammapult acquire --port COM4 --seconds N [--out file.csv]   # набор спектра
gammapult lin     --port COM4 [--codes "100 600 1300"] [--n 10000] [--period 100]   # самотест ЦАП
gammapult cmd     --port COM4 --send "-diag" [--read СЕК]   # произвольная команда
gammapult bootinfo --port COM4                   # загрузчик: ID МК, опции (только чтение)
gammapult flash   --port COM4 [--bin fw.bin] [--no-dbank-fix]   # прошивка (без --bin — встроенная)
gammapult dump    --port COM4 --out папка         # вся флеш и опции через загрузчик, дважды со сверкой
gammapult setpage erase|restore --port COM4 [--from папка]   # страница настроек 0x0801F000
gammapult fit     spec.csv [--lo 300] [--hi 7000]   # подгонка фотопика по CSV
gammapult log status|on 600 120|off|start|stop|time --port COM4   # регистратор
gammapult log erase --yes --port COM4                         # стереть журнал (необратимо)
gammapult log dump --port COM4 --out папка [--session N] [--thermo] [--sum]   # выгрузка журнала
gammapult calenc  c0 c1 c2 c3 c4                  # команды -cal для калибровки BecqMoni
gammapult obtest  --port COM4                    # проверка записи опций: DBANK=0 поверх DBANK=0, сверка
gammapult hvpeak  --port COM4 --start 700 [--target 1190] [--lo 300] [--hi 6000] [--count 3000] [--timeout 120] [--off]   # ВВ по пику
gammapult tc      --port COM4 [--secs 120] [--points N]   # запись термокомпенсации (оценка k1)
gammapult tpl collect --port COM4 [--n 2000] --out raw.bin [--baud 3000000]   # сырые порции (uint16 × 8192 подряд)
gammapult tpl build raw.bin [--out tpl.h] [--tail-out tail.bin] [--load --port COM4 [--save]]   # эталон и таблица хвоста из порций
gammapult adc dnl raw.bin [raw2.bin ...] [--out dnl.txt] [--load --port COM4 [--save]]   # поправка DNL АЦП по порциям
gammapult adc dnl dnl.txt --load --port COM4 [--save]                                   # записать готовую таблицу
```

`acquire --out` пишет CSV `channel,count`. `lin` печатает центроиды ступенек и прямую (как `gfw.py lin`).

`tpl collect` дописывает порции в файл по мере прихода (при сбое собранное остаётся) и печатает скорость,
порций/с. `--baud N` (600000, 1000000, 1500000, 2000000, 3000000; прошивка с командой `-baud`) — только для опытов:
на время сбора прибор и порт переходят на N (`-baud N` → `-ok baud N` на старой скорости → смена порта → проверка),
после сбора и при отключении — обратно на 600 000. Скорость не сохраняется во флеш; если пульт завис или убит,
прибор сам вернётся на 600 000 через 5 с без кадров (BecqMoni снова увидит его). Не вышло переключиться —
порт возвращается на 600 000, пульт ждёт 6 с сторожа прибора и сообщает об ошибке.

`tpl build` вместе с эталоном строит **таблицу хвоста** для разбора хвостовых наложений в детекторе
(`tpl_learn.cpp`, `build_tail`; порт `firmware/gamma_fw/tools/pileup/shape.py` с уточнениями). Берутся одиночные
импульсы с тишиной до +70 отсчётов после максимума, база — среднее спокойных отсчётов порции (как у детектора),
A и фаза — подгонкой нового эталона, как в приборе. Время импульса — 50 % фронта, смещение по фазе — медиана,
затем уточняется по общей форме. Форма S(τ) на сетке 1/16 отсчёта, хвост сглажен по соседним целым отсчётам.
Фазы делятся на 16 строк равными шагами по диапазону смещений. Строка `s[r][j−1] = κ_r·S(j − t_r)` (Q15,
j = 1…64, κ_r — масштаб строки), у вершины (j ≤ 4) поправка по импульсам строки. Отрицательная часть
(с ≈ +37) входит в таблицу. Печатается остаток одиночных после вычета хвоста по таблице (% A, норма ≲ 0.1 %).
`--tail-out` пишет `tail.bin`: `s` (16 × 64 int16 LE), затем `row[64]`, 2112 байт (для `tools/replay`).
`--load` пишет по шагам (`tpl::TplLoad`): `-tplw ×64`, `-tplok` (снимает прежнюю таблицу); только если они прошли
без `-err` — `-tlw ×64`, `-tlm ×4`, `-tlok`; затем `-save` (с `--save`). При ошибке эталона таблица и `-save` не
отправляются (rc 5). Ошибка таблицы (в т. ч. старая прошивка без `-tlw`) эталон не отменяет: rc 6, разбор не
включён. Таблица не построилась — только эталон, `pile=-` в `-gst`. Мастер (шаг «Форма импульса») и страница
«Эталон» пишут так же; ошибка таблицы — предупреждение, шаг засчитывается.

`adc dnl` считает **таблицу поправки дифференциальной нелинейности АЦП** (`adc_dnl.cpp`; SPEC §7.3, §9) по сырым
порциям с широким спектром (смесь, фон; эталон Cs до кода 2048 не достаёт): гистограмма кодов всех файлов, ширина
кода — отсчёты на код, делённые на локальную норму (медиана соседей ±16 кодов без выбросов). Центр кода — по
накопленной сумме ширин внутри группы выбросов (широкий код, пропущенные за ним, узкий). Горб базы и места, где
норма не годится (кривизна, перепад, много выбросов подряд), пропускаются; коды 0 и 4095 не берутся. В таблицу —
встречающиеся коды (ширина ≥ 0.1 LSB) с нормой ≥ 50 отсчётов на код и |сдвигом центра| ≥ 0.5 LSB, не больше 16
(с наибольшим |сдвигом|). Печатается каждая пара: ширина, сдвиг в LSB и в 1/16 LSB, отсчёты, норма. `--out` пишет
текст `код сдвиг_1/16` построчно (`#` — комментарий), его же читает `tools/replay` (7-й аргумент). `--load`: `-dnl clr`,
затем все пары одной командой `-dnl c1 o1 c2 o2 …`; `-save` (с `--save`) — только если обе приняты; ошибка — rc 5
(`-err unknown` — прошивка без `-dnl`). Вместо сырых порций можно дать готовый `dnl.txt` (только для `--load`).
Пример (прибор GS474-0001, 3.5·10⁸ отсчётов): `2047 +127` (код 2047 шириной 16.9 LSB — пропуск 2048…2061),
`2062 +26`, `767 +8`, `768 +11`, `1791 +12`, `1792 +17`, `1793 +8`.

## Сборка

Нужен **Visual Studio Build Tools 2022** (воркфлоу «Desktop C++»: MSVC, Windows SDK,
C++ CMake tools). Из корня репозитория:

```powershell
$cmake = "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe"
& $cmake -G "Visual Studio 17 2022" -A x64 -S host -B host/build   # configure (1 раз)
& $cmake --build host/build --config Release
```

Зависимости (Dear ImGui v1.90.9, ImPlot v0.16) подтягиваются автоматически через CMake
FetchContent (на этапе configure нужен интернет). Результат:
`host/build/Release/gammapult.exe` и `gammapult.com`.

## Структура

```
host/
├── CMakeLists.txt      # цели gammapult (GUI) и gammapult_com (CLI, SUFFIX .com)
├── cmake/embed_fw.cmake   # встраивание firmware/gamma_fw/gamma_fw.bin в пульт при сборке
└── src/
    ├── entry.cpp       # диспетчер режимов GUI/CLI
    ├── main.cpp        # окно Win32 + DX11 + цикл ImGui/ImPlot, панели и вкладки расширенного режима
    ├── ui_shell.*      # верхняя полоса, строка состояния, переключение режимов
    ├── ui_home.*       # главный экран
    ├── ui_wizard.*     # мастер настройки (9 шагов)
    ├── ui_adv.*        # расширенный режим (страницы)
    ├── devstate.*      # состояние настройки прибора, шаги мастера
    ├── i18n.* appcfg.* # тексты ru/en, настройки пульта
    ├── cli.cpp         # подкоманды CLI поверх класса Device
    ├── device.*        # сессия с прибором: -gst, очередь команд, самотест ЦАП, подстройка ВВ, сбор порций, термо
    ├── tpl_learn.*     # расчёт эталона формы по сырым порциям (порт tools/tpl_pmt.py)
    ├── adc_dnl.*       # таблица поправки DNL АЦП по плотности кодов сырых порций (adc dnl)
    ├── stm32boot.*     # загрузчик STM32 по USART (AN3155): стирание, запись, сверка, опции
    ├── fwflash.*       # прошивка прибора целиком (вход в загрузчик, DBANK, запись, проверка ответа)
    ├── peakfit.*       # подгонка фотопика гауссом, кодирование калибровки BecqMoni
    ├── logdump.*       # записи регистратора: разбор (logrec.c из прошивки), интервалы, выгрузка, термо, сложение
    ├── serial_win.*    # COM-порт через Win32 API
    ├── shproto.*       # кадры shproto (BecqMoni / AtomSpectra)
    └── theme.*         # тема и шрифты ImGui (латиница/греческий/кириллица)
```
