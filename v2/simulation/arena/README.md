# Арена 2026-10-10/11 — состязательная проверка спорных решений v2

По каждому вопросу два агента-адвоката доказывали противоположные позиции **прогонами**.
Каждый работал в своём каталоге `<вопрос>/A`, `<вопрос>/B`, исходные стенды не трогал.
Судья (`<вопрос>/judge`) перезапускал их команды, читал код в поисках нечестностей
(разные сиды и число событий, систематика только у одной стороны, утечка истинных
моментов в алгоритм, незначимые разницы) и делал контрольный прогон на общем стенде.
Недоказанное считалось недоказанным.

Цена: 9 агентов, 1.27 млн токенов, 1 ч 37 мин. Решения записаны в `../../decisions.md`
D12–D14, рабочий стенд по итогам — `../bench/`.

## Что нашлось попутно — важнее самих вердиктов

1. **Баг знака** в `../mc_csp.py::solve_cluster`: `tq - dt` вместо `tq + dt`. Из-за него
   «отрицательный результат» D11 и бит-в-бит одинаковые прогоны. Нашли независимо
   три адвоката, подтвердили два судьи. Исправлено.
2. **В стендах не было теплового шума АЦП** — только квант. У 16-битного АЦП на
   125 Мвыб/с это ≈100–200 мкВ, и именно он ломает детектор ступенек ЗЧУ (двойное
   дифференцирование). Вывод D7 «дизера нет, нужно 16 бит» — артефакт модели.
3. **«FWHM ∝ 1/fs» — систематический сдвиг детектора** на 1–1.4 отсчёта, а не шум.
4. **Робастная σ прячет хвосты.** Введены метрика `pk3` (доля событий фотопика с ошибкой
   < 3 %) и счётчик лишних оценок.
5. Стенд TIA завышал заряд втрое и не учитывал шумовое усиление `e_n·(1+Cin/Cf)` —
   на вывод не влияет, исправлено в `../bench/` (`--q 0.33333 --cin 6e-12`).
