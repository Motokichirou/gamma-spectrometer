# TIA v2 на OPA818 — SPICE (2026-10-11)

Проверка главного риска ветки TIA (`../../decisions.md` D12): реализуем ли TIA с Zt = 5 кОм
и полосой 26–50 МГц на реальном ОУ. Модель — официальная PSpice TI `opa818.lib`
(Rev. A, из `../../refs/sbomb74b.zip`), даташит `../../refs/opa818.pdf` (SBOS940B).

```
LTspice -b ac.cir           # АЧХ, перебор Cs 4/6/8 пФ × Cf 0.25…1 пФ
LTspice -b tran_noise.cir   # импульс фотопика без фильтра;  noise.cir — шум
LTspice -b filt.cir         # с RC-фильтром перед АЦП;      filt_noise.cir — шум
python analyze.py ; python analyze_filt.py
```

Схема: анод → −IN, +IN на земле, `Rf` = 5 кОм ‖ `Cf`, питание ±5 В. `Cs` — ёмкость анода
и дорожки **без** входной ёмкости ОУ (1.9 + 0.5 пФ, она в модели). `Cf` — полная, вместе
с паразитной ёмкостью резистора. Импульс: Q = 7.2 пКл (фотопик Cs-137, рабочая точка D4),
τ_d = 230 нс, фронт 3 нс.

## 1. Устойчивость — риск снят

| Cf, пФ | подъём АЧХ при Cs 4 / 6 / 8 пФ | f−3дБ, МГц |
|---|---|---|
| 0.25 | 2.2 / 3.2 / 4.0 дБ | 130–160 |
| 0.35 | 0.2 / 0.8 / 1.4 дБ | 120–135 |
| **0.5 и больше** | **0 / 0 / 0** | 87–93 при 0.5; 45–49 при 0.8; 34–36 при 1.0 |

При GBW 2.7 ГГц предел устойчивости около 0.35 пФ. **`Cf` выбирается по полосе, а не
по устойчивости**, и нужное значение 0.8–1.25 пФ — обычный C0G 0402 (минус ~0.1 пФ
паразитной). Прежний довод D5 п.4 «`Cf` 0.64 пФ нереализуема» относился к ОУ с GBW
~0.5 ГГц; для OPA818 он не действует.

## 2. Шум — нужен фильтр перед АЦП

Без фильтра шум e_n · (1 + C_вх/Cf) ≈ 2.2 нВ/√Гц × 11 тянется за полосу сигнала до
≈GBW/11 ≈ 250 МГц: на выходе **≈530 мкВ** против 188 мкВ, заложенных в стенд, и всё это
заворачивается в АЦП. RC-фильтр 100 Ом + C на землю на частоте ≈fs/2.5 это убирает:

| Cf | RC | fs | пик, мВ | σ (до 1 ГГц), мкВ | пик/σ | стенд: пик/σ |
|---|---|---|---|---|---|---|
| 0.5 пФ | 50 МГц | 125 | 132.7 | 238 | 558 | 714 |
| **0.8 пФ** | **50 МГц** | **125** | 131.2 | 176 | **745** | 714 |
| 0.8 пФ | 26 МГц | 65 | 128.2 | 116 | 1108 | 1495 |
| **1.25 пФ** | **26 МГц** | **65** | 126.2 | 90 | **1396** | 1495 |

Шум стенда — его же модель (`bench/tia.py`: Rf + e_n 4 нВ/√Гц с шумовым усилением при
Cin 6 пФ, один полюс, полоса до fs/2), пересчитанная на тот же делитель 100 Ом / 1 кОм.

**Итог: с фильтром OPA818 даёт отношение сигнал/шум на уровне стенда** (+4 % при
125 Мвыб/с, −7 % при 65). Значит, цифры `bench` (0.10 / 0.14 % FWHM) к шуму реального
TIA применимы — тем более что TIA в стенде ограничен алгоритмом, а не шумом.

## 3. Что ещё не проверено

- **Форма импульса** двухполюсная (TIA + RC), а не однополюсная, как в стенде. Это вопрос
  эталона, а не качества: эталон всё равно снимается с реального тракта (замер №4).
  Формы лежат в `pulse_k*.txt` — можно подставить в `bench`.
- **Потребление**: 27.7 мА при ±5 В ≈ **280 мВт** на один ОУ. В v2 бюджет USB 2.0 и так
  превышен (`../../design.md` §7.4), но это заметная строка.
- Корпус DBV — SOT-23-5, выводы: 1 OUT, 2 VS−, 3 IN+, 4 IN−, 5 VS+.
- Разводка: TI требует вырез полигонов под −IN и OUT, развязка 0.1 мкФ C0G + 2.2 мкФ
  ближе 6 мм (даташит §8.4).
