# bench — рабочий стенд v2 после арены

Скопирован из `../arena/d8/judge/` (стенд судьи D8), изменён только путь к корню проекта.
Обе ветки на одном коде, одни и те же зёрна и метрики, поэтому сравнение честное.

```
python arena.py tia --solver vp --redetect 2 --q 0.33333 --cin 6e-12 --adc-snr 73 [--fs 65e6] [--rate 3e5]
python arena.py csp --solver vp --detector lmax --redetect 2 --adc-snr 78      # ЗЧУ, в резерве
sh run_main.sh                                                                 # основная таблица TIA
```

Опции: `--seeds 1,2,3,4,5`, `--dur 4e-3`, `--sys none|static:+4|drift:4` (систематика τ_d),
`--slow 0.05` (медленная компонента), `--fit-td` (τ_d свободна у каждого события),
`--adc-snr` (тепловой шум АЦП, дБFS), `--vfs`/`--vramp` (шкала АЦП и рампа ЗЧУ), `--json`.

## Что отличает от `../mc_pileup.py` и `../mc_csp.py`

- **ГН/ЛМ по моментам с правильным знаком** и блочный МНК (`fitcore.py`);
- **повторный поиск в остатке** медленным детектором (`--redetect`);
- **тепловой шум АЦП** `σ = span/(2√2)·10^(−SNR/20)` (`--adc-snr`) — в старых стендах был
  только квант;
- TIA в рабочей точке D4: заряд ×1/3 (`--q 0.33333`) и шумовое усиление `e_n·(1+Cin/Cf)`
  (`--cin 6e-12`);
- метрики: **pk3** — доля событий фотопика с |ошибкой| < 3 % (видит хвосты, которые прячет
  робастная σ), счётчик **лишних оценок**, каждое истинное событие засчитывается один раз.

## Основная таблица: TIA, 14 бит/73 дБFS, 5 зёрен × 4 мс (`run_main.sh`, 2026-10-11)

FWHM электроники / светимость / pk3 / лишних оценок:

| fs, Мвыб/с | 300 кимп/с | 1 Мимп/с |
|---|---|---|
| 40 | 0.15 % / 99.5 % / 96.8 % / 5 | 0.20 % / 98.3 % / **89.6 %** / 52 |
| 65 | 0.12 % / 99.7 % / 97.6 % / 4 | 0.14 % / 99.0 % / **93.1 %** / 36 |
| 125 | 0.09 % / 99.9 % / 98.8 % / 6 | 0.10 % / 99.6 % / **96.2 %** / 31 |

Погрешности по зёрнам: FWHM ±0.00–0.01, светимость ±0.1–0.3, pk3 ±0.1–0.5 п.п.
С собственными 7 % кристалла полное FWHM во всех клетках ≈7.0 %. **Разница между частотами
видна только по pk3** — то есть по хвостам и потерям при близких наложениях.

⚠ **Это оптимистичная граница.** Эталон формы в модели известен точно, нет блуждания
базовой линии, послеимпульсов ФЭУ, объёмного заряда; реальная АЧХ TIA с `Cf` ≈ 0.64 пФ
не проверена. Цифры станут честными после SPICE-модели TIA и замера №4 на v1.
